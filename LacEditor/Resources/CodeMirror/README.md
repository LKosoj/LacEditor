CodeMirror 5.65.21 language modes and the standalone runMode shim are copied unchanged from the npm `codemirror` package. CodeMirror is copyright Marijn Haverbeke and others and is distributed under the MIT license in `LICENSE`.

`runner.js` is LacEditor's adapter for token ranges. It loads only bundled modules; document text is passed as data. `languages.json` maps the supported names to bundled mode/MIME pairs. This directory does not contain or run the CodeMirror editor or themes.

Source: https://github.com/codemirror/codemirror5/tree/5.65.21
