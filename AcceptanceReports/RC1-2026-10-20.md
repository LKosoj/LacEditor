## 性能数据与限制

全部数值为本次本机测试，不代表帧率或每次交互上限。UI 工作负载记录同步操作与 `layoutSubtreeIfNeeded` 耗时，不能等同于屏幕完整呈现时间。

| 工作负载 | 中位 / p95 / 最大（毫秒） |
| --- | --- |
| 约 0.8 MB Markdown 缩放，30 次 | 7.68 / 9.36 / 26.75 |
| 同文档滚动，30 次 | 8.55 / 15.03 / 15.45 |
| 同文档预览切换，30 次 | 9.34 / 12.07 / 12.40 |
| 50 MB 文档缩放，30 次 | 8.70 / 12.70 / 28.69 |
| 50 MB 文档跨区滚动，30 次 | 1.07 / 328.94 / 363.45 |

- 50 MB 首次进入尚未布局的远处仍有约 0.36 秒停顿；没有宣称消除首次深处布局开销。该用例主进程 RSS 从约 354 MiB 到 524 MiB，后段趋稳；不将此视为单文档净增量或完整 WebKit 内存。
- 十标签两分钟主进程 RSS 从约 277.5 MiB 增至 362.0 MiB，关闭九个后约 360.0 MiB。弱引用确认编辑器已释放，但 RSS 未立即明显回落，持续增长/分配器缓存仍需更长时间与 Allocations 归因，不声明已证明无泄漏。
- 预览专项主进程 RSS 约 148.5 → 峰值 151.3 → 136.1 MiB，关闭后约 137.4 MiB；不包含 WebKit 辅助进程总量。
- 1/10/20/50/100 MB 解码分别约 0.006 / 0.016 / 0.033 / 0.111 / 0.147 秒，这是后台读解码门禁，不是实际打开至首屏用时。
- 首次完整门禁与另一压力测试的编译重叠，10 MB 括号扫描超过原 1.5 秒门槛，退出码 133。未调整门槛；结束压力任务后单独复测通过，随后重新串行运行完整七阶段门禁并通过。保留失败与成功日志。
- XCTest/Analyze 保留已有第三方 Tree-sitter C 警告及本机 CoreSimulator 版本提示，没有把这些提示记为零告警。未扩大本轮范围修改第三方语法库。

## 隔离方法与证据

- `Verification/ReleaseCandidateVerification.swift` 只接受 acceptance 身份的两个构建，拒绝碰触已运行实例；使用临时 home 与临时文件。应用退出后直接读取其工作区及设置，而非仅根据截图判定恢复成功。
- 夹具使用 `ApplePersistenceIgnoreState` 排除 macOS 对测试身份的系统 Resume 状态，验证的是 LacEditor 自身工作区恢复；不等同于完整系统 Resume 验证。
- 辅助脚本按 AX 标题/描述识别分组；原生合并操作先展开系统窗口菜单、等待拆分动画完成，再执行。初期严格匹配标题及未展开菜单造成的脚本失败没有通过应用补丁绕过。
- `.build/rc1-acceptance.log`：首次含计时失败的门禁；`.build/rc1-large-files-serial.log`：单独复测；`.build/rc1-acceptance-serial.log`：最终七阶段通过。
- `.build/rc1-upgrade.log`：旧版升级、实际 Finder 打开、原生窗口菜单、Dock/关闭流水线。
- `.build/rc1-settings.log`：RC1/73 实际设置六轮焦点验证。
- `.build/rc1-endurance.log`、`rc1-preview-endurance.log`、`rc1-profile-standard.log`、`rc1-profile-50mb.log`：连续交互、释放与同步耗时。
- `.build/rc1-package.log`：最终签名打包；静态分析在打包前完成，ZIP 解压件再次验证，避免分析产物覆盖签名。
- 已安装 App 的 Info.plist SHA-256：`6048a9ec9c732be0b44be60e62d7860dab01540bb817fb055e764c7387dc4024`；可执行文件 SHA-256：`0363c3600b25fadd1e04baf5ead30806f095f74dbe8e95a717c8a94a4ee7bb1d`，前后一致。测试用旧版副本及验收 App 的 Launch Services 登记在结束后撤销。
