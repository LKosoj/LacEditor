# 界面实验 UI5 验收记录

日期：2026-10-20。版本：**0.15.0 · UI5（构建 68）**。
分支：`codex/flclash-ui-experiment`；UI4 基线 `c8158a1`。正式 `main` 仍为 `7024a03` / 0.14.4（63）。

## 交付范围

- 侧栏拖放显示前/后落位线、分组接收高亮，末尾落区 20 pt；只在松手后改变顺序。文件拖到收起组头约 550 ms 后展开，边缘 36 pt 根据距离滚动。
- 拖放离开、松手、取消或视图移除后停止局部计时器；普通悬停与空闲不轮询。筛选时不允许排序，避免改变未显示内容的相对顺序。
- 文件/分组使用独立 UTType；Finder 文件按 provider 顺序加载，目录、不支持格式与普通文字不写入侧栏。跨组仅复制引用，原文件和源分组保留。
- 修复自身落位意外挪到末尾；拖放辅助代码拆到 `SidebarDragSupport.swift`，与文件列表呈现分开。
- 统一分组、设置和体验入口的局部按下/悬停反馈。编辑区落位线与侧栏落位提示分开；保留原生窗口、标签、NT2 材质与预览分隔规则。
- 大文档的 TextKit 显示失效合并，布局返回后交给原生 API；限制额外预绘到可见区，保留已有定向预热。字体、基线、行距和输入法实现未改动。
- 编解码提示状态清除延至视图更新后，使用 generation 丢弃过期状态。
- UI4 示例库及用户修改沿用，不重复创建或覆盖。

## 性能测量

环境：Apple M4、16 GB、macOS 27.0.1、Xcode 27.1；优化 Release XCTest 宿主，同一 52,428,816 字节 Markdown、预览关闭、30 次窗口缩放与跨区域跳转。

| 操作 | UI4 基线中位 / P95 / 最大 ms | UI5 第一次 | UI5 最终复测 |
| --- | --- | --- | --- |
| 缩放 | 8.757 / 19.821 / 33.674 | 7.062 / 9.672 / 17.875 | 6.263 / 7.606 / 23.257 |
| 跳转/滚动 | 1.689 / 557.622 / 577.488 | 0.704 / 319.842 / 342.714 | 0.586 / 315.927 / 350.634 |
| 工作负载总时长 | 15.532 秒 | 11.794 秒 | 11.900 秒 |

- 同步跳转 P95 两次约 316–320 ms，较基线低约 43%；**仍有约三分之一秒停顿，没有达到无感深处跳转**。计时包含同步 AppKit layout，不是显示帧时间、端到端输入延迟或帧率。
- 基线宿主采样 RSS 约 336 → 峰值 546 → 477 MiB；UI5 最终约 372 → 峰值 544 → 537 MiB。初始值与系统回收有波动，最终驻留偏高，不能声称内存优化。峰值只来自离散采样，不含 WebKit 子进程。
- 采样归因：原生 `prepareContentInRect` → 非连续布局填补 → `FoldLayoutManager.invalidateDisplay` → 原生重绘路径 → `usedRectForTextContainer` / `_recalculateUsageForTextContainerAtIndex`，重复遍历早先的行片段。优化保留原生失效 API，只合并通知并限制多余预绘。
- 曾尝试仅设置 avoidAdditionalLayout，深处 P95 仍约 549 ms；该尝试已删除，没有保留无效分支。限制额外预绘单独约 544 ms，合并显示失效后才出现明显改善。
- 原生标签 100 次切换（最终 Debug 回归）中位 4.652 / P95 7.084 / 最大 10.820 ms；这是同步切换/layout 耗时，不代表物理输入到屏幕显示的延迟。

原始日志：`.build/ui5-baseline-large.log`、`ui5-layout-large.log`、`ui5-viewport-large.log`、`ui5-coalesced-large.log`、`ui5-final-large.log`；Time Profiler `.build/ui5-baseline-large.trace` / `ui5-time-samples.xml`。采集仅针对测试夹具，不针对用户正在编辑的正式 App。

## 边界与后续

- 真实指针拖放、途中反向/取消、拖到组头悬停展开的实际手感和逐帧 hitch 仍待人工确认；数据/几何单测不能证明视觉动效全部通过。
- UI4 窗口截图工具失败的限制在本轮重试时未复现，已捕获 `.build/UIExperimentSnapshots/UI5-window-{浅色,深色,跟随系统}.png`。只包含临时夹具内容；测试宿主的图标/版本不代表实际实验 App。静态截图不证明动态帧率和真实拖动体验。
- 前台中文输入法、多屏/非 Retina、VoiceOver、系统增强对比度与减少透明度、全屏及长时间完整进程树内存仍需后续检查。
- 第三方 Tree-sitter 编译/分析和 CoreSimulator 过旧提示仍单独保留；`WindowManager.activate` 仍有视图更新期间发布警告，未将其写作已解决。原编解码提示路径与标签失活清除路径已统一延后发布。
- 不推送 GitHub、不创建正式标签、不修改 `main`、`VERSION` 或正式元数据；保留原有未提交报告和旧安装包。
