# 25.6: запуск с путями из терминала

Предварительный план подготовлен GPT-6.1-Terra; реализация — основной агент, независимое review — Terra. Первичный источник: [Use Typora from Shell or Cmd](https://support.typora.io/Use-Typora-From-Shell-or-cmd/), дополнение [Typora 1.1](https://support.typora.io/What%27s-New-1.1/). Для macOS требуется системное открытие через `open -a` и прямой запуск binary с путём, включая предложение создать отсутствующий файл/папку. Точные детали нескольких аргументов Typora не проверены на Mac: порядок аргументов ниже является явным контрактом LacEditor. Windows/Linux/Chromium flags не добавляются.

1. В `LacEditorApp.init` один раз получить argv/cwd и до первого register передать позиционные пути в существующий WindowManager. Абсолютные/относительные пути, Unicode/пробелы, `--` для имени с дефисом; известный системный `-psn_…` пропускается. При неизвестной опции дальнейшие значения не считаются путями, чтобы её аргумент не стал именем нового файла.
2. Сохранить одну очередь раннего открытия с признаком разрешения создать отсутствующий CLI target. Пока окна нет, одинаковый ресурс/канонический путь объединяется; явное последующее открытие после регистрации не подавляется. Эта очередь уже подавляет startup default folder; существующая сессия/recovery восстанавливаются прежним порядком.
3. Существующий файл/каталог идёт по обычным openFile/openFolder. Для отсутствующего пути стандартный NSAlert предлагает файл, папку или отмену; trailing slash предлагает только папку. После ответа проверить активное состояние/окно и диск повторно; появившийся объект открыть без перезаписи. Создание — существующий FileService.createWorkspaceItem с выбранным родителем, без автоматического создания родителей и без изменения FileService.
4. Swift-тесты: argv и неизвестные опции, ранняя очередь и default folder, сохранность dirty документа, Finder/CLI duplicate, конкурентное появление, создание/отмена/смена окна, отсутствие родителей. Дополнительно нужны реальный direct binary, `open -a`, NSAlert и восстановление на Mac. Эти проверки не выполнены в Linux.

Статус: код и тесты подготовлены; независимое статическое review Terra не нашло новых конкретных дефектов. Это не подтверждение запуска приложения или всех пунктов25.6.
