# Перевод и модели функций

Согласованный объём: явный выбор языка перевода через LLM и отдельная модель каждой AI-функции. Подключения и API сохраняются; новые сервисы и маршрутизация не добавляются.

1. Перевод: 13 языков и свой вариант; переводится выделение, сохраняются Markdown, адреса ссылок, код и формулы. Проверка: тесты языка, инструкции и структуры запросов обоих текстовых API; смена языка отменяет незавершённый результат.
2. Модели: сохранённое имя модели для функции поверх профиля её типа. Для пользовательской проверки можно переопределить модель ещё раз. Пустое поле наследует значение. Проверка: сохранение настроек, старый JSON правил, порядок наследования.
3. Применение: ручные запросы, каждый пункт фонового пакета, метаданные, автодополнение, изображения, OCR и аудио используют выбранную модель. Проверка: подставные ответы и отмена устаревших результатов при изменении модели.
4. Интерфейс: ручное имя модели или список с текущего сервера, переводы на трёх языках; новый файл включён в Xcode и автоматически в SwiftPM.
5. Независимое ревью GPT-6.1-Terra, исправления и повторное ревью до чистого результата; собственные статические проверки.

Ограничение проверки: Linux без Swift/macOS SDK. XCTest, сборка, интерфейс и реальные запросы требуют Mac; успешный запуск не заявляется. Использован prompt-master для инструкции перевода. Настройки прежних подключений и сохранённые документы не изменяются.
