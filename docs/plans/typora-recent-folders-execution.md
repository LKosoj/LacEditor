# 25.6: недавние и закреплённые папки — план до кода

План подготовил GPT-6.1-Terra native_execution. Источник: https://support.typora.io/File-Management/ . Это следующая часть согласованного объёма, без нового хранилища или окон.

1. `RecentFilesStore`: отдельные URL папок и ключ UserDefaults, прежний лимит/порядок/дедупликация; существующий список файлов не менять. `SidebarLibraryStore`: optional pinnedFolderPaths в существующем JSON, отдельные операции закрепления/условной отмены, старые снимки совместимы.
2. Явное открытие через диалог/Finder/недавние/закреплённые проходит один AppState.openFolder(URL): проверка папки, установка существующего root, запись в recent. Недоступный путь сообщается через существующий feedback без удаления из списка и без изменения документов. Восстановление сессии и автоматическое назначение родителя нового файла не записывают новое явное открытие.
3. Существующие move/trash/undo WindowManager обновляют новые списки по компонентам пути. Возврат удалённого списка только при совпадении ожидаемого состояния; undo rename переводит обратно только сохранившиеся перемещённые записи, сохраняя последующие действия. Папки выводятся в имеющихся sidebar и меню; закрепление/удаление записи не трогает диск.
4. Swift-тесты: старые prefs/JSON, дедуп/порядок/закрепление, отсутствующая папка, перенос дочерних путей и undo после более поздней правки; открытие в активном состоянии. Независимый review после реализации. Реальные меню, несколько окон и macOS XCTest здесь пока не проверены.

Связь быстрого открытия с недавними/закреплёнными каталогами реализована следующим шагом и описана в typora-quick-open-execution.md; вся25.6 этим не объявляется завершённой.

## Реализация и проверка

Подготовлены хранение, совместимое чтение, существующие меню/боковая панель, общий явный openFolder и обновление путей move/trash/undo. Swift-тесты проверяют старые prefs/JSON, историю отдельно от файлов, условную отмену и недоступный путь; существующий interaction test расширен сценарием rename → новая папка в recent/pinned → физический undo. GPT-6.1-Terra review нашёл устаревающий путь при undo после новой записи, исправлено поштучным переводом сохранившихся записей. Повторное review не нашло новых конкретных ошибок. Реальные действия macOS, сборка и XCTest не запускались.
