# 25.6: папка при запуске — план до кода

Предварительная детализация GPT-6.1-Terra files_execution по существующим WindowManager/LacEditorApp/настройкам. Нативная macOS-команда `open -a LacEditor путь` уже использует маршрут Finder; второй CLI или установка shell-инструмента не нужны.

1. Необязательный по смыслу `startupFolderPath` (строка, пусто по умолчанию) в текущих настройках и UserDefaults; поле пути/NSOpenPanel ничего немедленно не открывают. Native готовит только эти поля, root — запуск и тесты.
2. Первый register применяет существующую restoration. После неё default выбирается только при пустом root и отсутствии ранней очереди Finder, один раз за запуск. Восстановленная папка и ранний file/folder URL приоритетны. Используется обычный AppState.openFolder(URL): проверка, сообщение об ошибке и recent, без изменения документов/сессии.
3. При Dock reopen default повторно не применяется. Поздняя папка Finder заменяет root обычным путём; поздний файл открывает документ, сохраняя уже выбранный root, как прежнее правило parent только при root=nil. Специальные флаги для перезаписи root не добавляются. Это уточнение согласовано с планировщиком до кода.
4. Swift-тесты: default/пустые старые prefs, сохранение значения, ранее выбранная папка, ранняя очередь file/folder, поздний Finder folder, повторный register/Dock, отсутствующий путь и сохранность dirty-документа. Реальная macOS launch/`open -a`/Finder и XCTest остаются отдельной приёмкой.

## Реализация и review

Настройки подготовил native_execution, WindowManager и тесты — root. Files_execution независимо проверил одноразовый флаг, приоритеты и дополненные тесты, включая настоящий WorkspaceSessionStore, ранний file/folder и Dock reopen; новых конкретных дефектов не найдено. Старые настройки сохраняют пустой default. Swift/XCTest, системный запуск и UI на Mac не выполнялись. Это не означает завершение остальных параметров совместимости25.6.
