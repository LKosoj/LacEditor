# Языки интерфейса

Читать при добавлении или изменении любого текста, который видит пользователь.

- Обязательно поддерживать упрощённый китайский (`zh-Hans`), английский (`en`) и русский (`ru`). Новые и изменённые пользовательские тексты добавлять сразу на всех трёх языках.
- Использовать существующий механизм `L10n` в `LacEditor/App/L10n.swift` и каталоги:
  - `LacEditor/zh-Hans.lproj/Localizable.strings`;
  - `LacEditor/en.lproj/Localizable.strings`;
  - `LacEditor/ru.lproj/Localizable.strings`.
- Получать текст через `L10n.tr`. В текущем соглашении ключом служит исходный китайский текст. Не вводить параллельный механизм переводов.
- Переводить меню, диалоги, ошибки, подписи, подсказки, названия действий отмены и подписи для средств доступности, включая AppKit и HTML предпросмотра.
- Системное имя готового приложения (`CFBundleName` и `CFBundleDisplayName`) — `LacEditor`: SwiftUI использует его как источник при повторном создании меню. Название development/experiment/acceptance-сборки в панели «О программе» берётся из `AppEnvironment.displayName`, который выбирает готовое имя по активному языку без показа китайского ключа при недоступной таблице локализации. Сохранять локализацию при переключении между окном редактора и настройками. Ссылка «О программе» ведёт на `https://github.com/LKosoj/LacEditor`.
- Окно настроек при создании восстанавливает сохранённый размер, но центрируется на видимой области экрана активного окна. Боковая панель имеет достаточную фиксированную ширину для русских названий разделов; названия не переносятся на несколько строк.
- Передавать переменные значения отдельно через параметры форматирования. Во всех переводах сохранять количество и типы подстановок; не строить ключи из имён файлов и других переменных данных.
- Сохранять одинаковый набор ключей без повторов в трёх каталогах. Проверять также ключи, передаваемые через переменные и значения перечислений: поиск только прямых вызовов `L10n.tr("…")` их не охватывает.
- Не переводить технические идентификаторы, сохраняемые значения перечислений, пути, расширения файлов, пользовательский текст и содержимое документов-примеров без отдельной задачи.
- Сохранять выбор «Как в системе / 中文 / English / Русский», применение после перезапуска и английский язык при отсутствии поддерживаемого языка системы. Изменять эту логику только в рамках явной задачи.
- Для изменения выбора использовать `L10n.saveLanguageSelection`: явный язык сохраняет также `AppleLanguages` для следующего запуска стандартных меню и диалогов; системный режим удаляет это переопределение. Сохранять ранний вызов `L10n.configure()` до создания редакторских состояний, а не переключать только отдельные представления во время работы.
- Для HTML предпросмотра использовать согласованный `L10n.languageCode`. Язык интерфейса не меняет язык кода документа, его текст и выбранную кодировку.
- Не добавлять зависимость поведения от переведённых фраз. Если затронут существующий код сравнения сообщений или их префиксов, проверить согласованность на всех трёх языках.
