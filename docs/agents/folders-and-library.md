# Рабочая папка, поиск папки и библиотека

Читать при изменении рабочей папки, поиска по папке, быстрого открытия, избранного, групп, недавних и закреплённых папок.

- Рабочая папка (`FolderWorkspaceStore`) принадлежит состоянию окна отдельно от библиотеки. В режиме дерева чтение/сортировка в фоне охватывают раскрытые каталоги; явный полный список использует один общий рекурсивный снимок. Результат проверяет корень, поколение и конкретный запрос; символические ссылки не обходятся. Повторно проверять корень и компоненты пути перед чтением, не выдавая такую проверку за атомарную защиту от подмены пути. Открывать файлы существующим `AppState.openFile`, сохраняющим идентичность документа. Корень, раскрытие, сортировка и вид дерева/списка сохраняются отдельно для каждой системной вкладки в совместимом формате сессии. Поддерживаются сортировки по имени, естественному порядку, созданию и изменению. Один FSEvents-наблюдатель корня обновляет только загруженные раскрытые каталоги и текущий список; при смене корня/закрытии освобождать его и отклонять старые события. Недоступный корень показывать как ошибку, не заменять домашним каталогом. Подготовлены создание/дублирование с отменой последнего действия через существующий sidebar feedback; системная история отмены текста не меняется. Перед удалением копии сверять снимок содержимого и документы всех окон по пути и идентичности, включая ссылки; чтение/удаление больших деревьев выполняется в фоне. Пересекающиеся открытия/сохранения координировать до завершения файлового действия; проверки не устраняют внешнюю файловую гонку. Подготовлены перенос/переименование и Корзина с последовательным подтверждённым закрытием; списки обновляются и отменяются адресно без затирания новых действий. При ссылке учитывать точный исходный URL открытого документа отдельно от цели, включая перенос родительской папки; если будущая относительная цель меняет ресурс, отказать до дисковой операции. Обратный перенос того же ресурса сохраняет новые изменения содержимого и не требует сравнения их с исходными байтами, в отличие от удаления копии.
- Поиск папки использует только выбранный корень и неизменяемые снимки открытых документов с главного потока; несохранённый снимок имеет приоритет над диском. Не обходить символьные каталоги, не угадывать кодировку; пропуски видны отдельно. Диапазоны/контекст в UTF-16. Перед переходом сверять документ, версию или состояние диска и исходный фрагмент, также после асинхронного открытия. Подключены контроллер состояния окна, ленивые строки поиска и ожидание штатного открытия placeholder. Snapshot callback возвращает nil при нестабильности состава/путей документов, не выдаёт неполный набор за успех. `@Published` сообщает до завершения изменения: дождаться устойчивого состояния на следующем шаге главного потока, затем повторно проверить загрузку, владение и отмену.
- `SidebarLibraryStore` хранит пути, группы и состояние раскрытия, а не индекс содержимого документов. Сохранять совместимость существующего JSON и атомарную запись. Избранное и группы не должны менять содержимое файлов на диске.
- Отмена изменения списка недавних файлов, избранного или группы применяется только если затронутый список не изменился позже. Не затирать более новые действия пользователя при отмене.
- `ExperimentSampleLibrary` подключается только для экспериментальной сборки; уже существующие файлы примеров не перезаписываются. Не добавлять автоматические примеры в обычный запуск.
- Сведения строки боковой панели обновляются при смене активности окна; команды контекстного меню не должны выбирать действия по сохранённому устаревшему признаку существования файла. Поведение меню при повторном открытии проверять на macOS.
- Выбор файлов боковой панели отделён от открытого документа и фокуса, ограничен одним видимым списком. Cmd/Shift, стрелки, Cmd+A и Return действуют только при фокусе строки; пакетная организация списка имеет одну отмену с прежней проверкой последующих изменений. Формат библиотеки не меняется.
- Быстрое открытие ⌘⇧O использует поиск имён текущей папки и `FolderSearchController`, но показывается плавающей панелью `QuickOpenOverlay` поверх редактора (в `MainWindowView`); боковая панель не открывается принудительно, её результаты быстрого открытия не показывает. Стрелки Вверх/Вниз, Return и Esc работают в панели; закрытие идёт через `cancelQuickOpen()`, после любого закрытия фокус возвращается прежнему респондеру или редактору (не во время marked text). Enter без совпадений оставляет панель открытой с сообщением. Точное имя ранжируется перед непрерывным и последовательным совпадением букв относительного пути, затем применяется прежний естественный порядок. Во время быстрого открытия запрос запускается после короткой паузы ввода, Enter открывает первый подтверждённый результат. Отдельного индекса и чтения содержимого нет; после открытия, смены режима или root запрос быстрого вызова снимается. Существующие проверки поколения и отмены сохраняются. Строки результатов — кнопки (`Button`, стиль `.plain`) с идентификатором по виду и пути, меткой и значением VoiceOver на кнопке; фон панели — Liquid Glass (`glassEffect`).
- `RecentFilesStore.folderURLs` хранит отдельную историю папок в `recentFolderPaths`; прежние `urls/recentFilePaths` остаются списком файлов. Закреплённые папки — optional `pinnedFolderPaths` существующего JSON `SidebarLibraryStore`, отдельно от избранных файлов и групп. Меню/боковая панель открывают их через `AppState.openFolder(URL)`; недоступный путь даёт существующее сообщение, не удаляя запись и не меняя документы/root.
- Диалог и явное открытие папки через Finder записывают историю после проверки каталога. Восстановление сессии и автоматический родитель нового файла не считаются новым явным открытием. Явно выбранная символическая ссылка на папку переводится в её канонический путь.
- Перенос/переименование и удаление папки обновляют связанные recent/pinned пути по компонентам, не строковому префиксу. При отмене переноса переводятся обратно только сохранившиеся перемещённые записи; новые записи и удаление старых не отменяются. Возврат удалённого списка и обычная отмена действия над списком выполняются только при совпадении ожидаемой коллекции.
- Быстрое открытие получает снимок закреплённых затем недавних папок из общих хранилищ и объединяет их с файлами одним worker. Пустой запрос показывает папки без обхода дерева; вызов доступен без root при наличии таких записей. Ранжирование имён общее, при равенстве порядок папок сохраняется. Перед публикацией и выбором проверяется неизменность списков. Типизированный результат папки вызывает `openFolder(URL)`, файла — прежний путь открытия; второй механизм окон не добавляется.
- Полный list папки использует существующий `FolderSearchService.listing`, без отдельного индекса и второго алгоритма обхода. `ListedFile` хранит даты отдельно от прежнего `File` (его равенство URL/relativePath сохраняется для поиска). Группировка использует относительного родителя и естественный порядок групп; направление применяется к файлам. Дерево продолжает читать только раскрытые каталоги. FSEvents любого потомка обновляет полный list, а смена root/mode/sort отменяет старую работу; частичные ошибки видны пользователю. Старый currentPath читается совместимо, но не ограничивает новый полный список текущим подкаталогом.
