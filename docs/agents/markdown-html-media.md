# HTML, изображения, медиа и оформленное копирование

Читать при изменении HTML-блоков, audio/video/iframe, SVG, GIF, Ruby, details, inline CSS, загрузки и управления изображениями, оформленного копирования.

- Подтверждённые общим cmark HTML-блоки разбираются SwiftSoup; исходные позиции остаются у cmark и последовательного HTMLContext. Только локальные audio/video воспроизводятся системным AVPlayerView без автозапуска; HTTP(S) media не передаются в AVPlayer даже после разрешения картинок. Remote iframe не получает WebKit: показываются fallback и ссылка для явного открытия во внешнем браузере. После ожидания проверяются документ, версия, поколение, URL, видимость и IME; раскрытие исходника, сворачивание, деактивация и уход с экрана останавливают и удаляют media view. Изменение высоты блоков обновляет frame видимых дочерних представлений. Скрипты и обработчики событий из документа не исполняются.
- Настройки изображений по умолчанию не отправляют данные. Ручная загрузка использует выбранный PicGo endpoint или пользовательскую программу; проверять реальные байты/MIME, порядок результатов и отмену. Включаемые отдельно автоматическая локальная/сетевая загрузка и разрешения YAML не должны менять старое поведение при отсутствии ключей. Копирование ресурса сохраняет исходный файл и не перезаписывает занятый путь; после записи устаревший снимок оставляет файл с сообщением о его расположении. Отмена текста не удаляет файл. Извлечение адресов HTML/reference подтверждается cmark, общие определения не должны менять невыбранные изображения и обычные ссылки. Число полных контрольных разборов не растёт с количеством definitions.
- Оформленная копия загружает выбранные подтверждённые удалённые изображения для RTF только при временном разрешении текущего `EditorDocument`, через отдельный display downloader/ImageIO; Copy HTML сохраняет адрес без загрузки. Перед `NSAttributedString.fromHTML` все оставшиеся HTTP(S) `img src` заменяются пустым data URI, чтобы скрытый системный importer не делал сеть. Перед записью буфера сохраняются проверки документа, версии, выделения, запроса, разрешения и самого буфера.
- Оформленное копирование пишет проверенные простой текст и HTML. RTF добавляется только после существующих проверок точности; если он не подходит, два остальных формата сохраняются с явным сообщением. Отмена, неактуальный снимок или неподдержанный выбранный фрагмент не должны затирать буфер. Команды копирования исходного Markdown и HTML сохраняют отдельное назначение.
- iPicUploader вызывает установленный iPic только по явной команде пользователя. Отмена ожидания не останавливает уже начатую внешнюю загрузку; неизвестный результат не выдаётся за подтверждённый URL. Ключи других загрузчиков сохраняются через существующий Keychain.
- Подтверждённые cmark HTML-блоки разбираются SwiftSoup как HTML5. Audio/video используют src/source и AVPlayer только с локальными адресами; отображение ограничено видимой областью и существующими проверками версии/отмены/IME/сворачивания. Исходник и undo от показа не меняются. Вложенные контейнеры и остальные незавершённые формы не объявляются поддержанными.
- Подтверждённый iframe отображается нативным `MarkdownHTMLBlockView` как fallback со ссылкой на внешний браузер, без WKWebView и сетевой навигации. Жизненный цикл связан с документом/версией/видимостью, есть раскрытие исходника. Содержимое script/style/textarea между cmark-узлами учитывается общим HTMLContext.
- HTML без оформления сохраняет семантику текста/ссылок/поддержанных медиа и подтверждённые стили самого HTML span, но опускает настройки нативных шрифтов, цветов и лигатур приложения. Неподдержанные элементы дают явное предупреждение. Произвольные scripts и event attributes не исполняются в приложении.
- GIF сохраняет многокадровые данные и воспроизводится системным NSImageView поверх пустого placeholder. SVG подтверждается полноценным XML-разбором без внешних сущностей и отображается через изолированный WebKit img с преобразованием в прозрачный PNG; исходные SVG bytes сохраняются для копирования/загрузки/экспорта.
- Копирование выбранного/всех изображений и скачивание всех сетевых используют существующий extractor и downloader, не перезаписывают файлы назначения и заменяют ссылки одной редакторской операцией с одной отменой. Повторы файла/URL используют одну копию; каждый SVG fragment сохраняется отдельно, а `%23` внутри имени остаётся частью имени. Undo текста оставляет созданные копии на диске. При отмене, ошибке или устаревшем снимке показываются уже созданные файлы; ссылки не применяются к другой версии документа.
- Remote изображения preview/PDF/PNG/formatted editor/Rich Copy загружаются только при временном `EditorDocument.allowsRemoteImages` (по умолчанию выключено) через `MarkdownRemoteImageDownloader`, не через старый PicGo/AI downloader. Display downloader использует ephemeral session без cookies/cache/credentials, запрещает redirects, проверяет фактический MIME, потоково ограничивает 8 МиБ на изображение, 32 МиБ и 32 запроса на batch и отклоняет очевидные loopback/private/link-local/CGNAT/ULA адреса. DNS-преобразование и адрес фактического соединения не закрепляются, поэтому полный anti-DNS-rebinding не обещается. Preview сначала показывает текст с placeholder и затем обновляет изображения в том же отменяемом задании; отзыв разрешения отменяет работу, а поздние результаты проверяют разрешение, документ, версию и поколение. PDF/PNG ожидают подготовку ресурсов. Ошибка отдельной картинки не останавливает остальные, исходник не меняется. SVG data URI отделяет base64 от fragment; display/copy/renderer сохраняют fragment per occurrence.
- Move/rename/delete изображения связывает файловый шаг и редакторскую замену одной custom undo-записью; обычная регистрация текста отключена только на время этой замены. Перед каждой стороной undo/redo проверять точный UTF-16 текст, ресурсы и подтверждённые ссылки открытых документов. Файловый конфликт оставляет обе стороны без изменений и не регистрирует redo; ошибка редактора вызывает обратный файловый шаг, не гарантируемый при внешнем конфликте. Уже совершённая либо частичная дисковая операция сообщает фактические известные пути. Новой системы async undo нет. Закрытые документы не сканируются. Копии remote после отмены остаются.
- Preview/PDF выводят audio/video/iframe только после общего cmark source/DOM proof; поддержанные nested ranges выбирают внешнее media. Remote audio/video получают пустой data URI и не загружаются, remote iframe заменяется fallback со ссылкой для явного внешнего открытия. CSP исполняемого HTML: `default-src 'none'; img-src data:; media-src data:; frame-src 'none'`. Локальные audio/video целиком читаются в data URI в фоне в прежнем задании preview: сначала текст/placeholder, потом ресурсы; PDF/PNG ожидают их. Это требует памяти под bytes/base64, новый streaming handler для local media не добавлен. Plain HTML export может сохранять remote media как исходные адреса в экспортном файле, но скрытый WebKit под тем же CSP их не загружает.
- Пользовательский inline CSS проходит общий Source/HTMLContext/DOM proof и типизированный MarkdownInlineStyle. Текущий первый срез принимает документированные red/yellow и положительный rem, не произвольные CSS-темы; CSS number проверяется отдельно от Swift Double. Unsupported style даёт читаемый source fallback в доказанных диапазонах и блокирует ресурсные загрузки; Copy пересекающегося неподтверждённого форматирования сохраняет прежний буфер. Нулевой размер не подменять системным шрифтом. Остальные цвета/единицы/свойства этим срезом не объявлены готовыми.
- Подтверждённый `details` использует первый `summary`, текст и поддержанные strong/em/span/ссылки через нативный TextKit. Системная кнопка меняет только временное раскрытие текущей версии редактора; исходный `open` задаёт начальное состояние и экспорт. При смене документа/версии временное состояние сбрасывается также после ввода и завершения IME. Вертикальное размещение использует существующие координаты медиа без второго поворота. Произвольные вложенные таблицы/медиа не объявлены поддержанными.
- `MarkdownRubyRenderService` рисует подтверждённые подписи через Core Text. Общий разбор обслуживает Parser/редактор/Renderer/Copy; base поддерживает подтверждённые bold/italic/цвет с наследованием, annotation сохраняет исходный родительский шрифт и цвет. Неподдержанные фон/размер/украшения и сложные rt остаются исходником по общему правилу допуска. Сохранять NSFont descriptor и координаты составных символов; измерение, рисование и раскрытие используют согласованную геометрию.
- Типизированный `display:none` хранится как `MarkdownInlineStyle.hideOnExport`. Нативное редактирование показывает содержимое; выходной CSS скрывает его. При наследовании скрытие предка сохраняется. Для форматированного Copy использовать `editingCSS`, чтобы копировать видимый результат редактора; исходное Copy Markdown не меняется. Само CSS-скрытие не обещает отсутствия загрузки ресурсов. Другие значения display не добавлять без соответствующей задачи.
- Форматированное Copy Ruby использует общий collector и DOM proof того же cmark-дерева, принимает целое подтверждённое выделение и передаёт base+reading без rp-скобок в plain text. HTML сохраняет ruby/rt/rp; RTF с неподтверждённой точностью не записывается. Неподтверждённый/незакрытый Ruby ограничивается исходным диапазоном до закрытия либо конца подтверждённого родителя, при непригодном диапазоне — EOF; частичное выделение не должно обходить этот барьер. Схлопываемые пробелы, emoji и дополнительные украшения требуют своего proof, не проецировать base+reading на исходные HTML-теги. Доступность сохраняет штатный source value/UTF-16 selection NSTextView без дополнительного дублирующего элемента картинки.
- Первый raw SVG-срез принимает самостоятельный подтверждённый cmark paragraph/HTML block. Source/DOM proof и системный XMLParser сохраняют исходные SVG bytes; отсутствующий стандартный xmlns добавляется только в подготовленные данные. Редактор использует прежний изолированный SVG loader, HTML сохраняет vector data URI. Стандартные initial fill/stroke допустимы в контролируемом оформлении; не требовать служебные opacity/stroke-width ради гипотетического стороннего CSS. CurrentColor/внешние зависимости/неподтверждённый viewport и неподдержанные формы остаются отдельными частями полного SVG. Файловые действия заново проверяют исходные ссылки, raw SVG не становится Markdown-ссылкой из-за синтетической presentation image.
- Одиночные `<audio …/>`/`<video …/>` обрабатываются как документированное расширение Typora только после exact standalone HTML-block/source/container proof. Нормализация в явную пару временно меняет literal того же дерева для общего DOM proof и всегда восстанавливается; Markdown не переписывается. Slash внутри quoted src не является концом тега. Не подменять старые многотеговые media по одному suffix `/>`; Copy принимает только весь подтверждённый исходный диапазон, не запускает сетевую загрузку и не пишет неподтверждённый RTF.
- Обычные текстовые HTML div/p/table отображаются нативным AppKit/TextKit viewer после общего source/DOM proof. Не расширять исключение WebKit для формул/диаграмм/внешнего медиа на обычное HTML-содержимое без отдельного решения пользователя. Новый generic WK viewer признан спорным отклонением и заменяется; основной LacTextView остаётся единственным редактором и владельцем source/undo/session. Не добавлять новые режимы и отдельные механизмы жестов/доступности ради этого блока.
- Основной Markdown сохраняет CSP `default-src 'none'` без script-src и прежний безопасный вывод: source scripts, event attributes и javascript URLs не исполняются. Внешние iframe в приложении больше не создаются, поэтому JavaScript-движок для них не нужен. Не разрешать scripts основного документа ради медиа. Проверки child/parent и поздней навигации в XCTest используют только тестовый loopback listener; это не сервер приложения. Реальный WebKit и внешний сервис проверяются на Mac.
- Обычные подтверждённые HTML div/p/table отображаются через `MarkdownHTMLBlockView` на AppKit/TextKit, без WebKit. Cmd-клик по подтверждённой ссылке открывает её; обычный клик раскрывает исходник (в summary details переключает раскрытие). Занятость ячеек таблицы хранится диапазонами IndexSet, без обхода каждой виртуальной ячейки colspan. Настройки абзаца и шрифта кода берутся из существующего редактора.
- Подтверждённый форматированный details проходит общий source/DOM-разбор также в предпросмотре и PDF/PNG, где исходное open определяет видимость body. Проверка не зависит от включения произвольных HTML-медиа: неподтверждённые теги не получают разрешение на исполнение.
- Форматированное Copy целого подтверждённого details использует снимок текущего раскрытия из Controller: он определяет plain и safe HTML и повторно проверяется перед записью буфера. Экспорт продолжает использовать исходное open. Целый подтверждённый raw SVG копируется существующим путём изображения; частичные/неподтверждённые диапазоны оставляют прежний буфер. Исходное Copy Markdown не меняется.
