# LacEditor 界面实验 UI9

版本：**0.15.0 · UI9（构建 72）**。分支：`codex/flclash-ui-experiment`。

UI9 的正式候选收尾为 **0.15.0 · RC1（73）**，详见 [候选版说明](RELEASE_CANDIDATE.md)。本页继续描述独立实验包，不将实验数据自动迁入正式 App。

本轮优先处理预览按钮、侧栏滚动条与悬停提示。沿用已有侧栏动效、操作反馈、文件筛选、设置修复与可编辑示例库，使用现有 SwiftUI + AppKit 实现，不需要安装 Flutter、Dart、Android SDK 或其他新开发环境。

## 安装体验

1. 先正常退出正在运行的旧实验版，再解压 `dist/LacEditor-0.15.0-UI9-72-arm64.zip`。
2. 将「LacEditor 实验版.app」拖入「应用程序」。保留原有的「LacEditor.app」。
3. 在「设置 → 关于」核对 `0.15.0 · UI9（构建 72）`。新用户从空白文档开始；已有实验版用户沿用实验数据，只替换同名实验 App。

本机打包采用 ad hoc 签名，未进行 Developer ID 公证。若 macOS 阻止首次启动，按系统「隐私与安全性」中的提示允许打开。

## 构建

在 Xcode 打开 `LacEditor.xcodeproj`，选择 **LacEditor UI Experiment** scheme 后运行。该 scheme 使用优化的 `Experimental` 配置，适合比较日常操作体验。

终端打包：

```sh
./Scripts/package-experiment.sh
```

脚本复用 `.build/XcodeDerivedData`，生成一个约 3 MB 的 ZIP；不会安装 App、更新 Git 标签、推送 GitHub 或清理项目。`swift test` 仍用于本地测试；SwiftPM 命令本身不生成带实验版标识的 App 安装包。

正式 `Debug`、`Release` 的版本元数据和 `VERSION` 仍为 0.14.4（63）。在实验分支选择正式 scheme 会编译当前实验源码；要重建原正式界面，应先妥善保存未提交修改，再使用 `main` 的正式提交 `7024a03`。已安装正式 App 可以继续直接使用。

## 本轮变化与边界

- 右上角 Markdown 预览按钮仅在 Markdown 模式出现，使用原生工具栏的逐窗口隐藏能力，不留下禁用按钮或空白占位，也不影响其他窗口的显示状态。
- 侧栏原生滚动条以 60% 不透明度显示；系统「增加对比度」开启时保持 100%。保留系统样式、显示偏好和鼠标操作，不影响正文与设置窗口滚动条。
- 自定义悬停提示不再额外注册系统提示；同一时间只保留一个等待或显示中的提示。移开、滚动、点击、拖动、键盘操作、打开菜单、窗口缩放/失焦与控件移除后清理，延迟回调校验 generation；没有提示时不保留事件监听。
- 本轮不重写编辑器、侧栏动效或原生窗口结构；综合 Dock/Finder 生命周期、长期 WebKit 内存和完整键盘导航仍留待下一轮。

UI8 已有变化继续保留：

- 侧栏底部固定一行操作反馈：收藏、分组成员和最近记录的变更可点击「撤销」，恢复原顺序；后续修改了对应列表时拒绝覆盖。仅影响组织记录，不删除磁盘文件，不占用正文的 Command+Z 撤销栈。
- 提示约 6 秒后恢复为操作说明；鼠标悬停或聚焦撤销按钮时保持。提示只由独立底部视图订阅，出现/消失不移动列表与设置按钮。
- 自定义侧栏行、筛选框、设置分类与主题控件具有可见焦点描边；辅助窗口原生按钮沿用系统焦点环。按钮 Tab 遍历仍遵循 macOS「键盘导航」设置，不强行更改系统偏好。
- 编解码复制按钮显示约 3 秒「已复制」，与过期提示分开；查找/替换显示当前任务名称和替换数量。
- 文档向 AppState 转发的界面状态先去重，光标及重复未保存值不再导致相同通知。仅证明测得的通知减少，不代表整窗重绘数或显示帧率。

UI7 已有变化继续保留：

- 展开、收起统一 200 ms 的无回弹曲线，箭头同步转动；标题和文件行自然尺寸保持，仅改变列表裁切高度。中途反向从当前显示位置继续，不添加内容淡入淡出。
- 裁掉的区域同时限制点击/拖放命中，避免收起或部分展开的文件行拦住后续模块。
- 使用侧栏视图的原生 display link 按屏幕刷新推进边缘滚动，最大速度仍约 420 pt/s；开始时逐步加速，跨行保留速度，换边不延续旧方向。
- 鼠标松开、离开视口、窗口隐藏/关闭、视图移除后清理回调与悬停任务；普通悬停不启动刷新跟踪。继续遵循系统减少动态效果设置。
- 补充连续几何采样与真实指针验收。原生侧栏整体开关、编辑器、字体、行高、NT2 材质和窗口生命周期逻辑保持；本轮不声称所有显示器已达到满帧。

UI6 已有变化继续保留：

- 设置展示延至按钮/菜单事件结束；应用尚未激活时通过一次系统激活通知完成展示。窗口关闭后清理等待，不定时抢回焦点。
- 按钮提示只在前台 key window 展示，失焦、关闭、移除或应用失活时立即取消；提示面板不能接受焦点。
- 重复激活相同工作区不再重复发布更新；窗口注册移出 SwiftUI 更新事务，关闭和切换工作区统一维护状态订阅。
- 行数和行索引采用顺序 UTF-16 与 Foundation 分块读取，保持所有换行语义；取消隐藏标签、非活动会话和缩放期间的布局预热。
- 增加十个标签两分钟连续切换与关闭释放、设置生命周期和拖放计时回归。字体、基线、行高、中文输入法和原生标题栏结构不变。
- 深处跳转仍主要耗在 AppKit 字体属性修复，未关闭原生字体修复、裁剪文档或引入另一套编辑内核；本轮性能测量和边界见 UI6 验收。

UI5 已有变化继续保留：

- 文件拖到行上半部/下半部时显示前/后落位线；分组头接收文件时显示描边，约 550 ms 后展开收起的组。文件和分组末尾各有 20 pt 落区。
- 拖放到列表上下约 36 pt 边缘时按距离连续滚动；普通悬停不启动滚动。离开侧栏、取消、松手或关闭视图后清除提示，计时器只在拖放期间存在。
- Finder 多文件拖入按原顺序处理；跨分组复制引用，不移动磁盘文件或从原组删除。筛选期间禁用侧栏拖放排序，避免将可见部分顺序误认为全组顺序。
- 大文档重绘通知合并到当前布局返回之后，再由 AppKit 统一处理；限制额外预绘到可见区域，原有定向预热继续保留。深处编辑、撤销和组合输入有专门回归。
- 分组/设置按下反馈与体验入口悬停保持局部颜色变化；滚动条遵循系统显示偏好。原生标题栏、标签、侧栏材质和预览分隔规则保持，并加入深浅/跟随系统、900/1180 pt 窗口几何检查。

UI4 已有变化继续保留：

- 侧栏顶部固定文件筛选，按文件名、扩展名、父目录或分组查找侧栏记录；不搜索正文、不做同步磁盘扫描。筛选时自动显示匹配项，清除后保持原有折叠偏好。
- 文件行显示文件名与目录、低饱和类型图标、当前文件的细标记和圆点；窗口失活时转为中性选中态。
- 空白文档中显示打开文件/体验文档入口，直接输入后消失；提示不替换编辑器，保留输入焦点和真实撤销。空白 Markdown 分栏开启时不叠加快捷入口。
- 首次升级 UI4，在实验版 Application Support 的 `ExampleFiles` 下后台准备 8 份模拟内容并追加三个侧栏分组，收藏体验文档；不改原有用户文件、不自动开标签、不制造最近文件记录。
- 示例只创建缺失文件，后续启动不重复导入，不覆盖你的修改；删除/移除过的内容仅在你右键「打开体验文档 → 补充缺失的示例文件」后补回。该操作也会重新加入示例分组与体验文档收藏。

UI3 的预览变化继续保留：

- Markdown 使用 15 px 系统字体、1.7 行高与最大 760 px 阅读宽度，重新调整标题、列表、引用、表格和代码块的间距；宽表格、长代码仅在局部横向滚动。
- 编辑更新现有页面，主题复用解析正文；预览保留滚动比例及表格/代码横向位置。「重新载入」恢复最新内容，不必再输入。
- 原生分栏隐藏时暂停渲染，重开时保留 WebKit 实例与分栏比例。分栏开关即时完成，避免宽度动画反复触发正文重排；真实撤销、选区与编辑器实例保持已测试。
- 侧栏标题与分组补充展开状态描述，键盘聚焦也能看到箭头及标题操作；减少动态效果时不播放悬停动画。
- 预览继续禁用文档 JavaScript，并限制资源为内联样式与 data 图片；不加载网络或本地路径图片，HTTP/HTTPS 链接由浏览器打开。
- 隐藏后的预览保留一个 WebKit 实例和已解析正文，有一定驻留内存成本；短循环测试不能证明长期无泄漏。50 MB 首次深区跳转仍有停顿，UI5 同夹具同步跳转 P95 从约 558 ms 降至 316 ms；这不代表帧率或端到端输入延迟。

UI1/UI2 已有变化继续保留：

- 设置左侧为五个分类，右侧分组并滚动；设置窗口默认 820 × 640，最小内容区 720 × 520。重复打开不重置已有分类，关闭后再次打开从编辑器分类开始。
- 查找窗口始终显示两种输入，选项集中一行，所有操作放在底部；转义说明仍为悬停显示。最小内容区 620 × 350，可调整窗口大小。
- 编解码窗口使用统一的标题、双栏表面和底部操作，保持自动换行与非模态；结果过期后禁止替换正文。
- 状态栏按宽度逐步隐藏次要信息，行列和任务信息优先；侧栏选中态区分窗口激活状态，并提供轻量按下反馈。
- 原生窗口/标签/标题栏继续负责窗口行为；侧栏使用系统 `.sidebar` 材质，跟随窗口激活与外观状态。
- 统一侧栏的标题、文件行、悬停、选中态、文件夹展开图标和完整路径提示；减少多余分隔线。
- 折叠仅改变标题下方内容的可见高度，避免整块平移与淡入淡出；UI7 将展开/收起统一为 200 ms，减少动态效果时直接切换。
- 删除滚动条配置中的整窗重复遍历；后台加载文件存在状态和身份；工具栏合并刷新并跳过相同呈现状态。
- 保留现有文本排版、字体、输入法、行号、编辑操作和 NT2 原生标题栏材质路径。

## 建议这样试用

1. 点左下方「打开体验文档」，开关 Markdown 预览，拖动分隔线，按回车/Tab/Shift+Tab 编辑嵌套列表。
2. 打开 `preferences.json`，用 ⌥⌘L 格式化，检查顺序与中文；打开 `sample.js`，观察注释边界和括号配对。
3. 在顶部筛选框输入 `js` 或「写作」，再清除，检查折叠状态是否恢复；切换深浅色并收起侧栏。
4. 打开「滚动与布局」里的两份文件，快速滚动、缩放窗口、开关换行，观察行号和正文是否对齐。
5. ⌘T 新建空白标签，直接输入、撤销并切换标签；修改示例、保存、退出和重开，确认内容保持。
6. 将 `sample.js` 拖到 `preferences.json` 的上下半部，观察前后落位线；拖动分组到末尾、悬停在收起的组上，以及拖到长列表的上下边缘，检查展开与滚动。按 Escape 取消后顺序应保持。

8 份文件共不到 1.5 MB，都是虚构内容；不是 50 MB 性能达标证明。需要更大文件时继续使用下面的可选测试，不随安装包自动生成大文件。

## 可选性能复测

以下测试只使用临时夹具，不读取用户文档；默认 `swift test` 跳过压力负载：

```sh
LACEDITOR_UI_STRESS=1 swift test -c release --filter UIExperimentTests.testProfileInteractionWorkload
LACEDITOR_UI_STRESS=1 LACEDITOR_PROFILE_SIZE_MB=50 swift test -c release --filter UIExperimentTests.testProfileInteractionWorkload
```

十个原生标签的两分钟压力测试（约 2 MB/标签，使用临时夹具）：

```sh
LACEDITOR_UI_ENDURANCE=1 swift test -c release --filter UIExperimentTests.testNativeTabEnduranceAndClosedEditorRelease
```

输出的同步操作耗时包含 AppKit layout，不能当作显示帧时间；RSS 仅覆盖 XCTest 宿主，不包括 WebKit 子进程。完整设计保存在 [实验方案](FLCLASH_UI_EXPERIMENT_PLAN.md)。先体验独立候选包，确认后再决定合并正式版；多屏、非 Retina、VoiceOver、真实指针/IME 与长时间内存检查仍需继续。

侧栏真实指针验收（先通过完整门禁以生成当前代码的隔离 App；需要本机辅助功能授权，关闭已运行的验收 App）：

```sh
swiftc -parse-as-library Verification/SidebarPointerVerification.swift -o .build/sidebar-pointer-verification
.build/sidebar-pointer-verification '.build/AcceptanceDerivedData/Build/Products/Release/LacEditor.app'
```

增加 `LACEDITOR_INTERACTION_POLISH=1` 同时检查右键收藏/从分组移除和底部撤销；该流程仅修改临时夹具。`LACEDITOR_UI_SNAPSHOTS=1` 可额外保存夹具截图。

工具只接受 `com.laceditor.acceptance`，启动时设置独立临时 home 并生成模拟侧栏；检查连续反向点击、真实拖动边缘滚动、悬停展开和 Esc 取消，正常退出后移除临时文件，不操作已经运行的实例。可加 `LACEDITOR_UI_SNAPSHOTS=1` 捕获该夹具窗口的静态画面；不包含用户文件，也不能作为帧率证明。
