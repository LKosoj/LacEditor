# LacEditor 1.0.0

Первая стабильная версия. Редактор для кода и обычного текста теперь полноценно работает с заметками в Markdown: оформленное представление с таблицами и изображениями, wiki-ссылки, теги, сборка рукописи и ИИ-помощник. Системные окна и вкладки macOS, файлы и рабочее пространство сохраняются.

## Добавлено

- **Оформленный Markdown**: переключение между исходником и оформленным текстом в одном редакторе, нативные таблицы с редактированием ячеек, флажки задач, изображения, формулы, диаграммы Mermaid, сноски, HTML-блоки и медиа.
- **Заметки и связи**: wiki-ссылки с подсказками имён файлов, обратные ссылки, теги в YAML и в тексте, шаблоны, заметка дня.
- **Рабочая папка**: дерево и список файлов, поиск и замена по папке, закреплённые и недавние папки, обновление ссылок при переименовании файла.
- **Письмо**: режим чтения, режим без отвлечений, фокус на абзаце или предложении, режим печатной машинки, ежедневная цель по словам, статистика, сборка рукописи из нескольких файлов, правки CriticMarkup, перенос разделов в оглавлении.
- **ИИ**: переписывание, проверка согласованности, взгляд читателя, задачи и решения, «Вопрос к документам» с проверяемыми цитатами и поиском в интернете, поиск источников через Jina, создание и описание изображений, распознавание текста, голосовой черновик, генерация Mermaid. Всё выключено по умолчанию, ИИ-серверы и модели задаёте вы.
- **Импорт и экспорт**: встроенный Pandoc 3.13 без отдельной установки; импорт DOCX, ODT, RTF, EPUB, FB2, HTML, LaTeX и PDF с текстовым слоем; экспорт в HTML, DOCX, ODT, RTF, EPUB, FB2, LaTeX, простой текст, PDF, MediaWiki, RST, Textile и OPML.
- **Правка и команды**: палитра команд (⇧⌘A), операции со строками, переключение комментария (⌘/), история версий файла, окончания строк и выбор кодировки при сохранении и открытии.

## Улучшено

- Поиск и замена перенесены во встроенную панель над редактором: счётчик «N из M», подсветка совпадений, регулярные выражения и целые слова. Добавлен переход к строке (⌘L).
- Быстрое открытие (⌘⇧O) стало плавающей панелью над редактором и находит также папки.
- Предпросмотр Markdown следует за прокруткой редактора, подсвечивает код по языку и показывает загрузку и ошибки с возможностью повтора.
- Меню перегруппированы, набор кнопок панели инструментов по умолчанию сокращён; сохранённая конфигурация панели не меняется.
- Настройки получили поиск по разделам, разбивку раздела ИИ на сегменты и сообщения об ошибках рядом с полем.
- Боковая панель поддерживает клавиатуру, выбор по набору букв, множественный выбор и VoiceOver.
- Текст интерфейса стал контрастнее и масштабируется по системной настройке размера.
- Открытие больших рабочих пространств и обновление предпросмотра, статистики и сворачивания выполняются в отменяемых фоновых задачах.

## Важно при обновлении

- Настройки, избранное, группы и рабочее пространство сохраняются; каталог данных приложения удалять не нужно.
- Максимальная ширина Markdown по умолчанию теперь 760 пт. Если эта настройка ни разу не сохранялась, ширина изменится один раз; в настройках можно выбрать «без ограничения».
- Прежние ИИ-функции объединены, их настройки переносятся автоматически.

## Загрузка и установка

- Версия: **1.0.0, сборка 79**.
- Подходит для **Mac с Apple Silicon и macOS 26 или новее**.
- Скачайте `LacEditor-1.0.0-arm64.zip`, закройте старую версию, распакуйте архив и перетащите `LacEditor.app` в «Программы» с заменой старой версии. Номер версии можно проверить в разделе «Настройки → О программе».
- Приложение подписано локальной подписью ad-hoc, нотаризации Apple Developer ID нет. Если при первом запуске система заблокирует его, разрешите открытие в разделе «Системные настройки → Конфиденциальность и безопасность».
- Для проверки целостности загрузки рядом лежит файл `LacEditor-1.0.0-arm64.zip.sha256`.

## Ограничения

- Сканированные PDF без текстового слоя не импортируются.
- Встроенные CSS-стили поддерживаются выборочно, произвольные CSS-темы не применяются.
- Автоматического обновления и облачной синхронизации нет.
