# LacEditor 0.15.0

本版将 UI1–UI9 与三轮候选验证的改进纳入正式版，重点打磨侧栏、文件整理、设置和 Finder 打开体验。保留 macOS 原生窗口标签、标题栏材质以及现有文件与工作区。

## 新增

- **侧栏文件筛选**：按文件名、扩展名或分组名称快速定位收藏、分组和最近文件。
- **更顺手的整理**：拖放显示落位提示，支持悬停展开分组、边缘自动滚动；收藏、分组和最近文件操作提供就地结果与撤销。
- **文件关联设置**：查看常见文本格式当前默认应用，在安装版中按格式点击「设为默认」。不会自动接管文件类型，尊重 macOS 确认与单文件设置。

## 优化

- 统一侧栏展开收起、悬停、按下与拖放反馈，内容裁切展开，减少标题跳动；弱化原生滚动条并遵循系统辅助功能设置。
- 设置按用途分类，补充侧栏、主题与设置选项的键盘焦点反馈。
- 改善 Markdown 预览的阅读层级、更新反馈和滚动位置保持；非 Markdown 模式隐藏右上角预览按钮。
- 减少重复界面通知、行索引扫描与大文档重绘，隐藏窗口及缩放期间避免多余布局预热。
- 编解码复制后就地显示「已复制」，不挤动按钮或遮盖错误提示。
- 设置按钮按下背景与悬停背景尺寸一致；移除上方常驻说明，保留文件操作与撤销反馈。

## 修复

- 修复完全退出 App 后双击关联文件，只出现 Dock 运行标记却没有窗口的问题，不再需要额外点击 Dock。
- 保留已有未保存标签、跨窗口文件去重与工作区恢复；关闭最后空白窗口后，通过 Finder / Dock 重开仍可使用侧栏和新建/关闭标签快捷键。
- 修复设置窗口打开后焦点回到主窗口的问题。
- 修复悬停提示重叠、残留，以及取消的延迟提示再次弹出的问题。
- 修复预览工具栏初始显示与语言切换时的状态更新。
- 开发、验收、实验和临时打包 App 不再参与常见文本文件的关联推荐，减少访达「打开方式」中的历史副本；默认应用设置失败或未确认时不误报成功。

## 下载与安装

- 版本：**0.15.0，构建 76**，已去掉 RC 标记。
- 适用：**Apple Silicon Mac，macOS 26 及以上**。
- 下载 `LacEditor-0.15.0-arm64.zip`，正常退出旧版后解压，将 `LacEditor.app` 拖入「应用程序」并替换旧版。在「设置 > 关于」核对版本。
- 升级沿用原有设置、收藏、分组和工作区；不要删除应用支持目录。正式版不包含「打开体验文档」入口或自动示例。
- 本机 ad-hoc 签名，未进行 Apple Developer ID 公证。首次启动如被系统拦截，请在「系统设置 > 隐私与安全性」允许打开。

## 验证与已知限制

发布构建、XCTest、静态分析、文件读写与大文件门禁，以及隔离 App 的冷启动、退出恢复、无窗口重开和设置焦点验证，详见仓库中的 `AcceptanceReports/0.15.0-2026-10-21.md`。候选阶段的长时间滚动与内存边界仍保留在报告中，不宣称全部消除。

- 第三方 Tree-sitter C 仍有既有编译与静态分析告警。
- 未穷尽所有多屏、系统外观和真实输入法组合，不将自动化检查视为全部人工验收。
- 不包含自动更新、网络、登录或云同步功能。
