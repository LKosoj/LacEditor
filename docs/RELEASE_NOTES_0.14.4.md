# LacEditor 0.14.4

本次更新汇总 0.14.0～0.14.4 的本地迭代，重点改善 macOS 原生标签、查找替换与窗口关闭体验。

## 新增

- 使用 macOS 原生标签栏，支持拖动排序、拖出为独立窗口及合并窗口，保留新建标签和数字切换快捷键。

## 优化

- 编辑内容滚入标题栏时使用系统磨砂效果，Markdown 预览同步适配顶部安全区。
- 侧边栏开关移到侧边栏顶部右侧，随侧边栏宽度对齐；收起后仍可通过工具栏展开。
- 查找与替换合并为独立非模态窗口，查找框、替换框和全部操作同时显示。
- Command+F 定位查找框，Command+Option+F 定位替换框；查找框支持 Return 查找下一处、Shift+Return 查找上一处。
- 单次替换后自动查找下一处，空查询禁用操作；转义字符说明通过 ⓘ 悬停查看。
- 同一标签组切换时同步侧边栏开关状态，兼容旧版工作区的标签顺序和未保存内容恢复。

## 修复

- 修复关闭标签时选择“不保存”后标签仍未关闭的问题。
- 修复 Command+W 直接关闭最后一个有内容标签所在窗口的问题：现在先保留空白标签，再关闭空白标签才关闭窗口。
- 修复关闭全部窗口后重新打开可能触发的界面更新重入崩溃。
- 保留 Finder 打开文件、跨窗口文件去重及退出恢复行为，避免覆盖已有草稿或恢复已确认关闭的内容。

## 下载与安装

- 版本：0.14.4，构建：63。
- 适用：macOS 26 及以上、Apple Silicon Mac。
- 下载 `LacEditor-0.14.4-arm64.zip`，退出旧版后解压，将 `LacEditor.app` 拖入“应用程序”并替换旧版。
- 安装包采用本机 ad hoc 签名，未进行 Apple Developer ID 公证。首次打开如被系统拦截，可到“系统设置 → 隐私与安全性”允许打开。
- 工作区数据独立于 App 保存。升级无需删除应用支持目录。

SHA-256：`b0c7b84008fbf3937c1968c9bbf2195475dea4690fab145ed9b728ce06032c78`。发布附件同时提供校验文件。
