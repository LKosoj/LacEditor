## 3. Имя и правки

Решение: **`MarkdownSourcePositions`** — структура верхнего уровня (`struct MarkdownSourcePositions`), файл `Preview/MarkdownSourcePositions.swift` (как в главном плане). Имя `MarkdownSourcePositions` в проекте свободно. `typealias Source` не создаётся, в `MarkdownPresentationParser` ничего не остаётся. Вложенный тип становится `MarkdownSourcePositions.TableCellPositions`.

Правки обращений (механические, одной командой, затем проверка `rg '\bSource\b'` и `rg 'PresentationParser\.Source'` — остатков быть не должно, кроме чужих `...Service.Source`):
- во всех файлах из п. 2: `MarkdownPresentationParser.Source` -> `MarkdownSourcePositions` (включая `.TableCellPositions`);
- в `MarkdownPresentationParser.swift` (только строки вне 3589–4769): `Source(` -> `MarkdownSourcePositions(`, `source: Source` -> `source: MarkdownSourcePositions` (в т. ч. `Source?`), `Source.TableCellPositions` -> `MarkdownSourcePositions.TableCellPositions`. Комментарии и строки не трогать.
- Длинные строки после замены не переформатировать.

Перенос блока: строки 3589–4769 вырезать из парсера и вставить в новый файл, снять один уровень отступа (4 пробела) — иначе стиль файлов верхнего уровня нарушится; другие изменения в теле запрещены. Пустую строку 3588 перед `struct` удалить, чтобы `enum` закрылся сразу после последнего члена.
