# LacEditor × FlClash UI 实验方案

日期：2026-10-20。状态：UI0、UI1 及 UI2 已实施；UI3 待继续。安装与构建见 [实验版说明](UI_EXPERIMENT_README.md)，实际验证范围见 [UI2 验收记录](../AcceptanceReports/UI2-2026-10-20.md)，历史记录保留在 UI1 验收文档。

## 1. 目标与实验边界

将 LacEditor 改造为视觉统一、操作连贯的桌面编辑器。借鉴 FlClash 的表面层级、列表组件、细腻反馈和可中断动画，保持 SwiftUI + AppKit + TextKit 1。主窗口、侧边栏、工具栏、设置和辅助窗口允许重新设计。

正文仍是主要工作区域；默认 14 pt、现有系统字体组合、行距、输入法、行号、语法高亮与编辑操作沿用现有逻辑。视觉改造不顺带重写文本排版。新建、保存、关闭确认、工作区恢复、多窗口、原生标签仍需完整工作。

采用同一项目目录、单一实验分支，不新增 worktree。已从正式提交 `7024a03` 建立 `codex/flclash-ui-experiment`；聊天分支不等于 Git 分支。正式基线为 0.14.4（63），当前验收报告删除与未跟踪文件保留，不自动纳入界面变更。

实验 App 显示名为“LacEditor 实验版”，Bundle ID 为 com.laceditor.ui-experiment，设置页显示“0.15.0 · UI2（构建 65）”。正式 App 暂不更新。技术路线已锁定为现有 SwiftUI + AppKit，不新增 Flutter 等开发环境。

## 2. 研究依据与取舍

本方案参考此前取得的 FlClash 源码快照 8d4f974；实施时记录实际采用的参考提交，不声称该快照始终为最新版本。

| 参考实现 | 借鉴点 | LacEditor 的处理 |
| --- | --- | --- |
| lib/ui/surface.dart | 页面、卡片、区块、输入面分级 | 收敛为窗口、侧栏、分组面、输入面，统一语义颜色 |
| lib/ui/collapsible_section.dart | 独立标题、内容高度过渡、正反向曲线、只处理有限可见条目 | 标题不被自身折叠带动，内容裁切收缩；尊重既有偏好，取消条目淡入淡出和逐项飞入 |
| lib/ui/navigation_dock.dart | 按压、跟手、落位分别配置弹簧 | 用于小控件与拖放反馈；正文和工具栏不做果冻拉伸 |
| lib/ui/page_transition.dart | 保留页面状态、避免整页透明度离屏合成 | 原生标签即时切换，设置内容可做轻微过渡；不套用 450 ms 全页滑动 |
| lib/ui/theme_cross_fade.dart | 主题一次更新，再处理视觉过渡 | 优先保证原生控件与 WebKit 同步换色，不逐帧重算编辑器；第一轮不做整窗截图动画 |
| Provider select / RepaintBoundary | 缩小状态订阅、隔离重绘 | SwiftUI 拆分可观察状态，AppKit 保持视图身份，避免整窗更新 |

借鉴设计与交互后独立实现原生组件。若需要复用源码或资源，先核查项目与依赖的具体许可并履行署名及分发要求。

## 3. 主窗口布局

默认窗口 1180 × 780 pt，最小 900 × 560 pt。所有尺寸均为逻辑点，工具栏高度由系统控制，不通过私有视图层级强行固定。

```
┌────────────────────┬──────────────────────────────────────────────┐
│ 红黄绿    侧边栏开关 │ 文档标题             撤销/重做  语言  预览     │
│                    ├──────────────────────────────────────────────┤
│ 收藏夹             │ 原生标签栏：两个以上标签才显示                 │
│   文件             ├────────────────────────┬─────────────────────┤
│ 分组               │                        │                     │
│   文件夹           │       编辑器           │   Markdown 预览     │
│     文件           │                        │                     │
│ 最近文件           │                        │                     │
│   文件             │                        │                     │
│                    ├────────────────────────┴─────────────────────┤
│ 设置               │ 保存/任务消息               编码 字数 行列     │
└────────────────────┴──────────────────────────────────────────────┘
```

- 主窗口保持平面分区，正文不用悬浮卡片、厚外边距或大圆角包裹。
- 侧栏从红黄绿区域贯穿到底部；标题栏保持现有 NT2 原生磨砂方向。
- 顶部右侧工具位置稳定。展开侧栏时按钮属于侧栏顶部，文档标题从内容区起始位置排列；侧栏收起后展开按钮保留在左上角。
- 原生分隔线只在需要区分区域的位置出现；预览分隔线在正文区域内终止。
- 窗口激活/失活采用系统材质状态，避免手动叠加另一层灰色遮罩。

## 4. 颜色、排版与基础尺寸

以下是调试起点，不作为覆盖系统无障碍外观的固定色。浅色编辑背景保持用户指定的 #FBFBFB。

| 语义 | 浅色起点 | 深色起点 | 使用规则 |
| --- | --- | --- | --- |
| 正文/预览画布 | #FBFBFB | #1E1F22 | 大面积稳定底色 |
| 侧边栏 | 原生 sidebar material | 原生 sidebar material | 跟随窗口活跃状态、透明度偏好 |
| 设置分组面 | #FFFFFF | #292A2F | 深色分组面比画布略亮 |
| 输入面 | 系统 textBackgroundColor | 系统 textBackgroundColor | 遵循输入控件外观 |
| 主要文字 | 系统 labelColor | 系统 labelColor | 不手动写死纯黑纯白 |
| 次要文字 | 系统 secondaryLabelColor | 同左 | 路径、说明、计数 |
| 强调色 | #5B61B9 | #A0A6F3 | 选中、焦点、主要动作 |
| 悬停底色 | label 的约 4% | label 的约 6% | 只改变底色，不改变行高 |
| 选中底色 | 强调色约 10% | 强调色约 17% | 不依赖颜色单独传达选中 |
| 边界 | 系统 separatorColor 的适当透明度 | 同左 | 按屏幕比例对齐 1 个物理像素 |

- 间距基准：4 / 8 / 12 / 16 / 24 / 32 pt。
- 界面字体：系统字体。正文 13 pt，侧栏文件 13 pt，组名 12–13 pt，中性说明 11–12 pt，设置页标题 20 pt。
- 编辑字体默认 14 pt，继续使用用户现有字体与行距设置，不因 UI 主题而更换字体。
- 图标以 SF Symbols 为主，工具栏交由系统；自定义行图标 14–16 pt，计数用等宽数字。
- 圆角：文件行 6 pt、设置组 10 pt、辅助输入区 6–8 pt。窗口与原生工具栏圆角由系统处理。
- 主要按钮使用强调色，次要按钮使用原生中性样式；危险动作只在菜单项或确认中使用红色。

## 5. 标题栏与工具栏

- 由 NSToolbar 和原生分栏结构承载，不覆盖红黄绿或自绘拖动区。
- 侧栏开关保持在侧栏顶部右侧，随侧栏边界调整；按钮约 28–32 pt 的可点击区域，图形遵循系统尺寸。
- 文档标题使用 13 pt 中等字重，单行尾部截断。只显示文件名，不再重复“— LacEditor”；完整路径通过悬停/原生文档菜单查看。
- 未保存状态优先使用系统文档修改标识，避免标题前堆叠多个圆点和图标。
- 撤销/重做保持紧邻的原生按钮组，按实际可撤销状态启用；更新不能造成按钮宽度跳动。
- 语言选择显示图标和中文模式名，预留稳定宽度；长名称截断，悬停显示全名。
- Markdown 预览开关在所有模式下保持位置，非 Markdown 禁用并说明原因。
- 窄窗口先截断标题，再将低优先级控件放入系统溢出区域；不能盖住标题、裁掉点击区或移动红黄绿。
- 不新增全局大搜索框、新建分组快捷条或常驻的编解码大按钮。

## 6. 原生标签

- 保留 NSWindowTabGroup 作为唯一标签实现，实验版不恢复第二套自绘标签栏。
- 单标签不显示标签栏；新增第二标签时由系统展示，标题栏和正文不能短暂出现多余空白。
- 选中态、分隔、关闭按钮、溢出、拖动与拖出由 AppKit 管理；不承诺通过公开 API 修改系统未开放的圆角、关闭按钮时机或精确标签宽度。
- 不在标签切换时对正文做淡入淡出、缩放或左右滑动；热点标签应立即响应。
- 保留数字快捷键、Control+Tab、Command+T 和现有保存确认。
- 最后一个有内容标签关闭后留下空白页，再关闭空白页关闭窗口；Dock 重开、Finder 打开、多窗口转移列为必测项。

## 7. 侧边栏详细交互

### 布局与模块标题

- 默认宽 250 pt，可在 210–340 pt 间调整；内容左右留 10 pt。最窄窗口允许拖动分隔线继续调整，不靠自动反复折叠适配。
- 保留收藏夹、分组、最近文件。模块间距 16 pt，模块标题高 28 pt；整体顶部 8–12 pt。
- 顶层标题不带图标。箭头放在标题/计数之后，占位宽度固定；仅悬停或键盘聚焦标题行时可见，不推动文字。
- 整个标题行可切换展开状态，右侧操作按钮有独立点击区，点击按钮不触发折叠。
- 新建分组入口放在“分组”标题悬停操作及右键菜单；不恢复旧的顶部“文件/新建分组”工具条。
- 清除最近记录使用标题右侧悬停按钮及菜单，提供准确确认，文字明确只清除记录。

### 分组与文件行

- 分组行高 32 pt，名称 13 pt medium；展开使用公开 API 可获得的打开文件夹符号，缺少合适符号时采用系统打开文件夹图像；关闭使用关闭文件夹。
- 分组折叠箭头如保留，同样在名称之后、固定占位，不能挤到行首；右侧显示文件数量。
- 文件行正常高 34 pt：16 pt 类型图标、文件名、必要时的收藏/缺失状态。路径不常驻占第二行。
- 相同文件名出现歧义时显示父目录，或在悬停时显示完整路径；需要第二行时固定为 44 pt，不能鼠标移入才撑高。
- 文件夹下文件缩进 16 pt。长文件名尾部截断，文件类型图标不压缩。
- 悬停与选中分别呈现；当前文档使用浅靛蓝底色和可访问性 selected 状态。窗口失活时保留可辨识的中性选中态。
- 文件缺失保持原位，使用次要警告符号与“文件不存在”说明，不闪动、不自动删除。
- 单击打开已有文件；已打开文件定位现有标签。右键保留新窗口打开、重命名、访达显示、收藏/移动分组、移除记录等现有能力。
- 删除分组与移除收藏明确为移除组织记录；真正重命名磁盘文件显示原文件名并处理冲突。
- 文件拖动使用系统拖动预览；插入位置显示细强调线，末尾可用落点至少 24 pt。放入折叠分组停留约 600 ms 可展开，快速经过不展开。

### 折叠、滚动与底部

- 内容始终在标题下方独立裁切区域中，从顶部锚定缩到零；不让内容上穿标题，不使用整个 VStack 的隐式动画。
- 当前模块自己的标题高度与基线不动；下方模块随内容高度连续移动，这属于正常让位，不能用“所有标题绝对不动”造成空洞。
- 展开 220 ms easeOutCubic，收起 180 ms easeInOut；取消淡入淡出、逐项错时和文字缩放。
- 中途反向操作从当前展示高度继续，既不排队，也不先完成旧动画。
- 长列表仅构建可见范围和少量缓冲，不为了动画测量全部文件；折叠后移除隐藏条目的命中与可访问性。
- 默认点击开关控制侧栏。保留已有“仅开关按钮悬停临时显示”的行为时，作为独立 overlay 状态：延迟约 300 ms、离开按钮和侧栏约 180 ms 收回；按钮在预览时不移动，点击直接固定展开，无先收后开。屏幕左边缘本身不触发。
- 固定展开/收起与临时悬停显示分开建模，只持久化固定状态。不得让 hover 直接改写正式展开设置。
- 底部设置行高 40 pt，图标+文字；悬停浅底色，不做悬浮胶囊。滚动内容不能覆盖设置行。
- 使用系统 overlay 滚动条，不强制黑色/白色、alpha 或常驻轨道。

## 8. 编辑区与 Markdown 预览

- 继续使用现有 NSTextView 和布局管理器。正文、插入点、行号和选区遵循一套现有坐标，不通过额外 baselineOffset 美化。
- 编辑区外观仅整理边界、空态和配色。保持现有最小内边距及首行与行号对齐；缩放窗口不通过重建文本视图完成。
- 当前行背景是静态低对比度色块；多行选区、括号配对高亮按现有编辑机制绘制，不额外动画。
- 空白文档保持可直接点击输入；可在不影响点击的区域给出低对比“开始输入，或拖入文件”说明，获得焦点/输入后隐藏，不做大型欢迎卡片。
- Markdown 开启时左右默认 1:1，记录当前窗口最近比例，单侧建议最小宽 300 pt；空间不足时约束比例，不遮挡正文。最小窗口若无法满足，允许更小的预览最小宽度并保持用户可关闭入口。
- 编辑与预览共用顶层材质策略，预览不再额外增加第二层厚标题栏。分隔线从正文内容边界开始，不穿过工具栏/标签栏。
- 预览正文使用系统标准字体，建议 15 pt、约 1.65 行高、20–24 pt 内边距，最大阅读宽度约 760 pt；源码字体和行距设置不应强行影响预览。
- 代码块使用系统等宽字体、轻底色、小圆角；表格局部允许横向滚动，不能撑大整个预览或遮住编辑区。
- 预览刷新不闪白、不反复淡入淡出；保留上一版直到最新版准备完成，再恢复滚动位置。加载消息只在确有等待时出现。
- 分栏开关可进行一次 180–220 ms 的宽度过渡；若实际导致 TextKit 布局掉帧则退回即时布局，先保证光标、首屏与行号稳定。

## 9. 状态栏与任务反馈

- 高度 24 pt，左右内边距 10 pt，11 pt 字体，背景与画布同色，上边缘仅一条细边界。
- 左侧保存状态改为中性色：已保存安静呈现，未保存用小圆点与文字，不常驻绿色勾和橙色大提示。
- 打开/保存/搜索/预览使用一致的细小进度指示与可读文字，超过约 200 ms 才显示忙碌状态；已知进度才显示百分比，不能编造进度。
- 可取消任务旁显示取消操作；保存失败和外部冲突不能被短暂成功提示覆盖。
- 右侧保留编码、字数、行列。语言已在顶部时可不再重复显示；缩进方式和 Tab 宽度仍只放设置，不加到状态栏。
- 窄窗口优先保留任务错误和行列，其次编码，最后隐藏低优先级字数；完整信息通过菜单/悬停可查看，不挤压重叠。
- 大文件模式保留紧凑入口与当前临时恢复项，避免弹出遮住正文的性能卡片。

## 10. 设置窗口

- 独立、非模态、可调整大小，初始约 800 × 600 pt，最小 680 × 480 pt，记住大小位置。
- 左侧约 156 pt 分类导航，右侧滚动内容；借鉴 FlClash 的分组设置行，改用桌面密度。
- 分类：编辑器、外观、文件与恢复、性能、关于。第一轮不加搜索设置，避免新增不必要功能。
- 右侧内容左右留 24 pt，标题 20 pt，分组标题 12 pt。分组表面圆角 10 pt，外部组间距 20 pt。
- 一般设置行最小高 52 pt，带两行说明时 64–72 pt；标题与说明左对齐，控件右对齐。长说明自然换行，整页可滚动。
- 开关采用系统 switch；枚举使用 popup/segmented；字体和行距同时提供步进控件与恢复默认。控件不改变整行尺寸。
- 编辑器：字体大小、行距、缩进方式、Tab 宽度 2/4/8、自动换行、行号。
- 外观：跟随系统/浅色/深色，状态栏显示，减少动态效果遵循系统；本轮不增加任意主题编辑器。
- 文件与恢复：现有退出行为、工作区恢复说明；未实现的自动保存功能不出现可启用开关。
- 性能：自动大文件模式说明及固定阈值，不开放未计划的阈值自定义。
- 关于：图标、LacEditor 实验版、完整版本及构建、系统与架构信息、项目链接和开源许可。
- 切换分类只更新右侧内容；保留各页滚动位置，允许约 120 ms 的局部淡变，不做主窗口重排。
- 打开设置后保持设置窗口焦点；主窗口后台状态刷新不抢前台。Command+W 关闭设置自身。

## 11. 查找与替换、编解码、提示和菜单

### 查找与替换

- 独立非模态窗口，两个输入框同时显示，不恢复模式 tabs。初始约 580 × 260 pt，内容按字体和控件自然布局，不靠过小固定高度裁切。
- 查找/替换标签宽度统一；输入框高约 28 pt；两行间距 10 pt。
- 下方一行转义开关、ⓘ、大小写选项；再下方一行状态；底部关闭、上一个、下一个、替换、全部替换。
- ⓘ 指针进入约 150 ms 显示说明，离开立即关闭，不抢焦点；说明层不接收鼠标事件、不推动布局，也提供键盘聚焦后的等价说明。
- Command+F/Command+Option+F 聚焦对应字段；Enter/Shift+Enter 和现有查找快捷键保持一致。
- 搜索消息就地更新，空查询禁用动作，全部替换作为一次撤销；后台任务结果不得应用到其他标签。

### 编码与解码

- 独立非模态窗口，默认约 760 × 520 pt，原文/结果左右对比，可拖动中间分隔线。
- 两栏标题、字符计数、内边距和边框完全对齐；内容自动换行，只垂直滚动。
- 底部状态在左，关闭/复制结果/替换原文在右；主要动作只保留一个强调按钮。
- 原文过期禁用替换并明确说明；保留现有 8 MB 提醒、32 MB 上限、取消和单次撤销语义。

### 全局控件、菜单和错误

- 原生菜单与右键菜单保留一致图标列、分隔和中文措辞；未实现命令不展示。
- 自绘悬停反馈 80–100 ms，点击反馈立即发生；不对每次点击都播放弹跳。
- 普通 tooltip 停留约 500 ms 显示，离开关闭，不设会一闪而过的短倒计时。包含快捷键时同时展示。
- 保存确认、外部冲突、编码无法表示字符使用原生 sheet；不更换成会被主窗口遮住的自绘卡片。
- 非阻断成功消息放状态栏，失败保留可操作入口，不能只用短暂 toast 交代重要结果。

## 12. 动效规格和状态约束

| 操作 | 建议起点 | 必须满足 |
| --- | --- | --- |
| 悬停 | 80–100 ms easeOut | 仅颜色/图标变化，不重排 |
| 按下 | 立即着色，释放约 100 ms 恢复 | 原生按钮遵循系统，自绘文件行不缩放文字 |
| 固定侧栏开关 | 约 220 ms 原生分栏动画 | 不重复触发，不在每帧重建编辑器 |
| 模块展开/收起 | 220/180 ms | 内容裁切，标题基线稳定，可反向 |
| 拖放落位 | 160–200 ms、轻阻尼 | 指针跟随不延迟、不队列化 |
| 标签切换 | 即时 | 不人为等待动画 |
| 预览分栏 | 最多 220 ms | TextKit 布局有压力时降级为即时 |
| 设置分类 | 约 120 ms 局部淡变 | 左侧导航固定，焦点可靠 |
| 主题 | 首先一次一致切换 | 不逐帧更新文本属性；暂不做整窗快照过渡 |

统一定义时长与曲线，限制动画作用域。遵循系统减少动态效果：关闭位移、缩放与弹簧，状态直接切换。提高对比度、减少透明度时使用可读的不透明语义背景。

## 13. 结构与性能实施

- 将 LacEditorDesign 扩展为颜色、排版、尺寸、Motion 四组语义配置；通过少量共享组件实现一致性，避免复制每个页面的按钮样式。
- 窗口层：EditorWindowLayoutState；工具栏层：ToolbarPresentationState；侧栏：库数据与局部悬停/折叠状态；正文继续由文档驱动。名称为建议，可按现有类型合理整合。
- 动画呈现进度与持久化展开状态分离，只有用户动作写入持久化状态；不把每帧动画进度写入 AppState。
- 滚动条配置只作用于自己负责的 scroll view，视图附着/外观改变时必要配置一次，删除每次 layout 的整窗递归和多次延时排队。
- 工具栏缩小订阅范围，只在文档名、dirty、语言、可撤销性、预览及侧栏状态变化时更新对应项；合并同一轮重复通知。
- AppKit hosting controller、NSTextView、WKWebView 保持稳定身份。rootView 赋值不等同于必然重建，要先用计数与 Instruments 核实，再消除确实冗余的更新。
- 文件路径检查、类型图标和父目录描述按 URL/版本缓存，不在每个动画帧做同步磁盘查询。
- 边界变化时只布局受影响区域；不在 SwiftUI body 读取会创建原生标签组的 AppKit 属性。
- 不新增持续 TimelineView/定时器驱动整个窗口；无任务时无持续动画与后台轮询。
- 每次动效调试都在普通文档和 50 MB 文档中验证；不通过降低编辑、搜索、保存能力换取流畅外观。

## 14. 同目录实验隔离

- 建立一个实验构建配置/共享 scheme，固定实验显示名、Bundle ID 和版本后缀。界面不提供旧版/新版两套运行时开关；正式历史由 Git 保留。
- 新增统一 AppEnvironment / AppDataLocations，使设置、最近文件、侧栏收藏/分组、Workspace、Recovery 全部使用实验命名空间。
- 当前三个存储实现仅特判 acceptance Bundle ID，新增实验 ID 而不改路径会落入正式目录；必须先解决此项再启动实验 App。
- 首次启动实验 App 使用空白工作区。可以提供明确的“一次性复制正式版设置与收藏”操作，复制后独立；不自动读写正式未保存内容。
- 实验 App 不声明 Finder 文档关联，不注册默认打开方式；通过应用内打开/拖放测试即可。独立 UserDefaults 与近期文档入口也要核对。
- 用户主动在两个 App 中打开同一磁盘文件仍会有编辑冲突，独立 Bundle ID 并不能隔离磁盘文件；保留外部版本检查，验收使用复制的测试文件。
- 不覆盖 /Applications/LacEditor.app。当前交付 LacEditor-0.15.0-UI2-65-arm64.zip，实验 App 可以单独使用；项目内不长期保留各轮解压 App，避免重复“打开方式”登记。

## 15. 推进顺序与每轮交付

| 阶段 | 范围 | 可验证交付 |
| --- | --- | --- |
| UI0 安全起点 | 同目录实验分支、正式基线、实验数据路径、scheme、性能基线 | 可启动但暂不改外观的实验 App，确认正式数据未变 |
| UI1 主界面 | 语义设计系统、窗口分区、工具栏、侧栏行与折叠、滚动条刷新收敛 | 第一份整体换肤安装包；重点对比展开、收起、拖动与输入 |
| UI2 工作体验 | 设置分类、状态栏、查找与编解码、提示和菜单统一 | 第二份完整交互安装包，键盘与窗口焦点回归 |
| UI3 预览与收尾 | Markdown 阅读样式、分栏过渡、深浅外观、无障碍与性能收尾 | 候选包、截图/短视频、性能比较、限制清单 |
| 正式替换 | 用户确认后合并实验分支 | 更新正式版本与发行说明，按既有工作区格式启动，保留回退版本 |

每轮只有在对应模块可用时才交付；不能把功能被临时关闭的外观样机称为完整实验版。每轮写清版本、修改范围、自动化结果、实际 UI 检查及未测项。

## 16. 验收标准

### 视觉与交互

- 在 900 × 560、1180 × 780、全屏、Retina/非 Retina 可用环境检查；没有遮挡、重叠、不可点击区域。
- 浅色、深色、跟随系统，以及窗口激活/失活下文字、选中态与原生材质一致。
- 连续快速切换侧栏 30 次、模块 50 次；无闪动、内容穿标题、按钮逃离指针、队列补播。
- 侧栏悬停临时显示若启用，验证按钮→侧栏→正文移动，单击固定、快速离开和拖文件进入。
- 设置/查找/编解码打开后不被抢焦点，Command+W 关闭当前辅助窗口；ⓘ 指针进入/离开使用真实鼠标验收。
- 标签切换、拖出、合并、多窗口、最后内容标签→空白→关闭→Dock 重开、Finder 打开保留专门回归。

### 编辑与性能

- 中文 IME、中英混输、首尾空行、Tab、行号点击拖选、撤销重做、折叠、括号高亮、Markdown 有序列表回归通过。
- UTF-8/UTF-16/GB18030 保存、保存中继续输入、外部修改冲突、退出恢复、取消任务不丢内容。
- 使用同一机器同一 Release 测量改造前后：标签切换、输入、侧栏动画、窗口缩放、预览开关及 RSS。
- 60 Hz 帧预算 16.7 ms，120 Hz 为 8.3 ms；以 Instruments 的实际掉帧/hitch 结果判断，不仅凭录屏观感声称满帧。
- 热标签切换继续目标 <150 ms；普通输入不得引入可感知延迟。大文件沿用既定性能目标。
- 先记录 20 次往返后的存活视图与任务、再循环测试，确认无持续增长；峰值、稳定值、机器与采样工具全部记录，不预先承诺未经测量的百分比提升。
- Debug/Release、Analyze、XCTest、run-acceptance.sh 按阶段执行，最终完整验收；第三方既有警告与未测硬件范围独立列明。

## 17. 本轮决策

推荐整体方向：原生窗口骨架 + FlClash 式柔和表面层级 + 桌面紧凑列表 + 小范围可中断动效。

主要视觉改造集中在侧栏、设置和辅助窗口；正文保持大面积平面画布，原生标签维持系统行为。整个改造必须让输入、查找、文件管理和恢复能力继续可靠工作。
