# Журнал изменений LacEditor

Здесь описаны изменения в каждой официальной версии LacEditor, которые заметны пользователю.

Журнал следует структуре [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
номера версий — [семантическому версионированию](https://semver.org/lang/ru/). Изменения описаны
на русском языке с точки зрения пользователя, без простого перечисления коммитов.

## [Не выпущено]

### Добавлено

- AI-агент в панели ИИ: читает открытые документы и файлы рабочей папки по явному запуску, с журналом каждого прочитанного файла и подтверждением каждого интернет-поиска; правки предлагает, а в документ и на диск пишет только по вашему действию («Принять», «Применить к файлам»); ведёт план, сжимает длинный контекст, предлагает готовые сценарии заданий.

### Улучшено

- «Вопрос к документу» передаёт следующим вопросам веб-источники прежних ответов и показывает кликабельными только их ссылки; страницы поиска усекаются до 16 000 символов; обрезанный по длине ответ модели показывается ошибкой.

### Исправлено

### Безопасность

- «Вопрос к документу» больше не включает интернет-поиск по умолчанию и перед каждым сгенерированным моделью запросом требует разрешения; повторный запрос спрашивает снова, а отказ не обращается к Jina и не добавляет источники. AI-агент перед первым чтением, получением оглавления или ссылок и предложением правки открытого документа вне рабочей папки запрашивает разрешение на этот документ для текущего разговора; после отказа его содержимое не отправляется.

## [1.0.0] - 2026-10-30

### Добавлено

- Улучшения для письма: режим чтения (`⌥⌘R`, только просмотр, Markdown показывается в оформленном представлении); в строке состояния отображается путь к элементу Markdown под курсором; статус сохранения различает сохранённое, несохранённое и состояние копии для восстановления, а также показывает время последнего сохранения; ежедневная цель по числу слов; режим фокуса может подсвечивать только текущее предложение; в палитре команд можно закреплять команды, а также показываются 5 последних команд.
- Разделы верхнего уровня в оглавлении можно переносить перетаскиванием или через меню (вместе с подразделами, одна отмена, уровень не меняется).
- Добавлена команда «Собрать рукопись…»: выбранные Markdown-файлы открытой папки объединяются в новую несохранённую вкладку, метаданные берутся из первого файла, относительные адреса превращаются в абсолютные, одинаковые метки сносок только сопровождаются предупреждением; исходные файлы не меняются.
- При переименовании или переносе Markdown-файла внутри открытой папки после подтверждения можно обновить указывающие на него wiki-ссылки и обычные ссылки; в открытых документах это можно отменить, в неоткрытые файлы запись идёт сразу.
- Добавлены правки CriticMarkup: подсветка и команда «Markdown → правки»; предпросмотр и экспорт по-прежнему показывают эту разметку как обычный текст.

- ИИ-функции объединены в «Переписать» (переформулировать/сократить/расширить/изменить тон), «Согласованность», «Взгляд читателя», «Задачи и решения»; у каждой функции есть пояснение «Нужно/Результат» (подсказка в меню, панель и настройки), старые настройки переносятся автоматически, в контекстное меню изображения добавлен пункт «Описать изображение с помощью ИИ».
- Добавлен «Вопрос к документам»: ответ строится только по текущему документу или выделению, документам, открытым в текущем окне, либо выбранным файлам, с проверяемыми цитатами, к которым можно перейти (если источник изменился, цитата помечается как устаревшая); разговор хранится только в памяти текущего окна, его можно сбросить кнопкой «Новый разговор»; если объём больше 50 КБ, нужно подтверждение; при включённом поиске Jina в «Вопросе к документам» можно отметить «Искать в интернете» (модель использует вызов функций, не более 3 раз на ответ, нужна поддержка сервера; при включённом Reader цитаты сверяются с содержимым страницы, веб-источники показываются отдельно и открываются только по клику). «Объяснить выделенное» стало командой меню этой функции, прежние функции «Объяснение» и «Решение по вопросу» удалены, их настройки автоматически переносятся в «Вопрос к документам».
- Улучшения для заметок и редактирования: палитра команд (⇧⌘A, список доступных команд меню); «Правка → Строки» (дублирование, перемещение, удаление, объединение, сортировка строк) и переключение комментария ⌘/; после сохранения записывается версия файла macOS, «Просмотр версий…» позволяет сравнивать и восстанавливать версии, есть «Сравнить с файлом на диске…»; в строке состояния показываются и преобразуются окончания строк (LF/CRLF/CR), добавлены «Сохранить в кодировке…» и «Открыть заново в кодировке…».
- В Markdown добавлены wiki-ссылки `[[файл#заголовок|текст]]` (оформленное отображение, переход по ⌘-клику, подсказки имён файлов после `[[`, в предпросмотре и экспорте заменяются обычными ссылками); в боковую панель добавлены разделы «Обратные ссылки» и «Теги», поиск тегов по папке находит и теги YAML, и встроенные в текст `#теги`, в оформленном представлении встроенные теги выделяются цветом.
- Добавлены «Новая заметка из шаблона…» и «Заметка дня» (Настройки → Файлы и восстановление → Шаблоны и заметка дня); в поиск по содержимому папки добавлены переключатели учёта регистра/регулярного выражения/целого слова и режим «Заменить» (предпросмотр, выбор отдельных пунктов флажками, после подтверждения заменяется выбранное; в неоткрытых файлах запись идёт сразу и не отменяется, в открытых документах это одна замена с возможностью отмены).
- Улучшения интерфейса: поиск и замена теперь во встроенной панели поиска над редактором, она показывает «N из M», подсвечивает совпадения в видимой области, поддерживает регулярные выражения, целые слова, ⌘E для поиска по выделению и закрытие по Esc; добавлен переход к строке (⌘L), позицию курсора в строке состояния можно нажать; быстрое открытие (⌘⇧O) стало плавающей панелью над редактором и больше не раскрывает боковую панель принудительно.
- Боковая панель поддерживает навигацию с клавиатуры, выбор по набору букв и VoiceOver; в заголовке окна есть меню пути к файлу (⌘-клик); в настройках добавлены поле поиска, сегменты раздела ИИ (Функции/Подключения/Проверки/Jina), подтверждение удаления и ошибки рядом с полем; предпросмотр Markdown следует за прокруткой редактора, эти сведения о позиции прокрутки не попадают в экспорт, копирование и PDF.
- Меню перегруппированы (команды буфера обмена Markdown перенесены в «Правка», сворачивание — в «Вид», ИИ-команды сгруппированы по функциям, добавлен псевдоним ⌘= для увеличения шрифта); набор кнопок панели инструментов по умолчанию сокращён до боковой панели, заголовка, поиска, языка, режима Markdown и предпросмотра, сохранённая конфигурация панели инструментов не меняется.
- Дальнейшая доработка интерфейса: в меню форматирования Markdown добавлены сочетания ⌘K, ⇧⌘K, ⇧⌘X и ⌥⌘1–6 и подменю «Изображения», добавлено меню «Справка»; папку можно открыть перетаскиванием в окно; пустой документ предлагает «Открыть папку…» и недавние файлы; быстрое открытие подсвечивает совпавшие символы; предпросмотр показывает загрузку и ошибку с возможностью повтора, печать и PDF всегда в светлой теме; поиск в настройках прокручивает к найденному и подсвечивает его, настройки изображений вынесены на отдельную страницу, адрес PicList больше не стирается из-за ошибки формата; в ИИ-панели запуск и остановка находятся на одном месте, изменение входов только помечает результат устаревшим, подсказки по написанию поддерживают подсветку по словам и «принять все»/«отклонить все»; стрелки раскрытия и кнопки заголовков в боковой панели всегда видны, при ошибке рабочей папки можно выбрать другую.

- Добавлены системные цвета, уровни оглавления, локальный каталог emoji, недавние и закреплённые папки и быстрое открытие; Yams и SwiftSoup обеспечивают YAML и HTML5. Оформленное копирование всегда проверяет простой текст и HTML и добавляет RTF только после проверки точности.

- Добавлены число слов по читаемому содержимому и настраиваемая скорость чтения, ширина Markdown, координаты нативных почтовых ссылок, экспорт flow/sequence и диаграмм, а также параметры страниц/метаданных PDF и экспорта HTML. Родительская папка Finder и файлов использует существующую координацию окон.

- Доработаны нативные таблицы: неполные строки, вложенность в списках и цитатах, многострочные ячейки, перетаскивание строк и столбцов, диалоги ссылок и изображений для виртуальных ячеек; ввод в ячейке пересчитывает только текущую строку. В рабочую папку добавлены сохранение состояния для каждой вкладки, сортировка, вид дерева/списка и отслеживание изменений. Также добавлены конфигурации экспорта, пользовательские команды, печать/PNG, локальные компоненты MathJax, Mermaid и преобразования буфера обмена.

- Добавлены флажки задач, клавиатурные операции со списками, нативная сетка таблиц с командами строк и столбцов, диалог ссылки, сноски, локальные отдельные изображения, дерево рабочей папки с файловыми операциями и поиском, режимы письма и статистика по исходнику/выделению; автоматическое парное закрытие символов включается по отдельности и по умолчанию выключено. PDF теперь использует системную печать WebKit.

- В меню форматирования Markdown добавлены команды создания трёх видов списков, блока кода и разделителя из обычных строк; в экспорт добавлены MediaWiki, RST, Textile и OPML на основе встроенного Pandoc.

- В перевод добавлены явный выбор целевого языка и пользовательский язык; для каждой ИИ-функции и каждой своей проверки можно отдельно выбрать модель, адрес, ключ и протокол берутся из соответствующего подключения. Смена языка или модели делает прежние результаты устаревшими.

- Добавлены ручные ИИ-инструменты с шестью независимыми переключателями: контекст выбранных документов, сравнение версий, своя проверка, распознавание изображений/PDF, голосовой черновик и генерация Mermaid (объяснение выделенного вошло в «Вопрос к документам»). Используются API шлюза для PDF/аудио и встроенный Pandoc, запись требует действия пользователя и системного разрешения; результат вставляется только после предпросмотра.

- ИИ: надёжность: поддерживаются ограждения кода ```json; элементы, которые не удалось проверить, пропускаются с показом их числа; запрос ждёт не дольше 10 минут; различаются таймаут, отсутствие сети, сервер не найден и сбой защищённого соединения; ручная отправка больше 50 КБ требует подтверждения «Всё равно отправить», фоновая обработка при превышении не запускается, после отправки показываются источник и размер.

- Добавлены команды помощника по письму, которые включаются по отдельности, предпросмотр правок и их отмена, переход к фрагментам терминов/противоречий, вставка резюме, серое продолжение текста, метаданные; поддерживаются текст, Decisions, изображения и пользовательские модельные серверы. Орфография и грамматика используют системную проверку macOS. Поиск источников и чтение веб-страниц используют Jina с настраиваемым адресом. Всё по умолчанию выключено.

- Добавлен режим без отвлечений для текущего окна (⇧⌘J): скрывает боковую панель, предпросмотр, номера строк, строку состояния и панель инструментов, а при выходе возвращает прежнее состояние. Переключатель боковой панели перенесён в «Вид», ⌃⌘B сохранён.
- Встроен Mermaid 12.2.0: блоки кода mermaid показываются в локальном предпросмотре, поддерживаются обновление темы и отдельное сообщение о синтаксической ошибке.
- В Markdown добавлено меню форматирования: полужирный, курсив, зачёркивание, встроенный код, заголовки уровней 1–6 и цитата; работает в исходном и оформленном представлениях, каждое действие отменяется отдельно.
- В боковую панель добавлено оглавление текущего документа Markdown, нажатие на заголовок переходит к нему и разворачивает свёрнутые области; после изменения устаревший список временно не позволяет переходить. Результат разбора общий с оформленным редактированием.
- В Markdown добавлено переключение между исходным и оформленным текстом; в одном редакторе показываются заголовки, полужирный и курсивный текст, зачёркивание, код, ссылки и цитаты, а в редактируемом абзаце видны маркеры синтаксиса.
- Встроен Pandoc 3.13, отдельная установка не нужна; Markdown можно экспортировать в HTML, DOCX, ODT, RTF, EPUB, FB2, LaTeX, простой текст и PDF. Экспорт использует текущий несохранённый текст и не меняет исходный документ; PDF теперь идёт через нативную печать WebKit.
- Добавлен импорт DOCX, ODT, RTF, EPUB, FB2, HTML и LaTeX с преобразованием в новую несохранённую вкладку Markdown, доступные встроенные и локальные изображения сохраняются, исходный файл не меняется. PDF с текстовым слоем импортируется постранично, сканы без текстового слоя не импортируются. Сложная вёрстка и размеры изображений могут не сохраниться.

### Улучшено

- Акцентный цвет по умолчанию заменён на системный; приглушённый текст и комментарии стали контрастнее; номера строк выравниваются вправо, ширина зависит от числа цифр; текст интерфейса использует системные семантические шрифты и масштабируется по системной настройке размера текста.
- Горизонтальный отступ редактора не меньше 16 пт; внимание: максимальная ширина Markdown по умолчанию теперь 760 пт. Пользователи, у которых эта настройка ни разу не сохранялась (в том числе те, у кого «без ограничения» раньше обозначалось отсутствием значения), один раз получат 760 пт; в настройках можно выбрать «без ограничения», после этого выбор сохраняется.
- Подсветка сохраняет необработанные диапазоны и пересчитывает их при прокрутке, учитывая диапазоны изменений синтаксиса Tree-sitter; при превышении его существующего ограничения по размеру используется прежний путь лексического анализа.
- Предпросмотр Markdown и статистика теперь работают в отменяемых задачах; разбор cmark для предпросмотра по-прежнему выполняется последовательно. Диапазоны сворачивания вычисляются в отдельной фоновой задаче, старый результат не перезапишет новый ввод.
- Боковая панель поддерживает выбор с клавиатуры и множественный выбор внутри одного списка, существующие операции упорядочивания выполняются пакетно с одной отменой.
- Рабочее пространство сначала читает метаданные и передаёт копии для восстановления по файлам, затем по одному читает тексты, выбранные вкладки обрабатываются в первую очередь; сохраняются сохранение, закрытие и проверка идентичности файла для ещё не загруженных документов.
- Детали интерфейса: строки результатов быстрого открытия стали кнопками с фоном Liquid Glass, улучшены подписи VoiceOver; в поле поиска добавлена кнопка очистки; имена в боковой панели обрезаются посередине, избранное, файлы групп и группы можно перемещать вверх/вниз через контекстное меню с отменой; поиск в настройках больше не указывает на повторяющиеся или скрытые строки, Esc очищает поиск, у отключённого сервиса Jina поля скрыты.
- Предпросмотр: блоки-уведомления окрашиваются по типу, добавлены стили mark, kbd, сносок и списков задач, блоки кода подсвечиваются по языку (в предпросмотре и PDF/печати), полоса цитаты, флажки и выделение следуют системному акценту, для пустого документа показывается подсказка; стили высокой контрастности и печати согласованы.

### Изменено

- Третий этап завершил выбор архитектурного направления по внешнему исследованию: сохраняется TextKit 1, эксперимент с TextKit 2 и переход на NSDocument не проводятся, подготовительный слой адаптации и разделение крупных классов отложены.
- В записи восстановления добавлено необязательное поле isDirty, старые записи по-прежнему восстанавливаются как несохранённые; рабочее пространство version 1 не меняется.

## [0.15.0] - 2026-10-21

Официальная версия, сборка 76. В неё включены улучшения, прошедшие проверку в UI1–UI9 и RC1–RC3; сохраняются существующие настройки, избранное, группы и рабочее пространство; экспериментальные идентификаторы, вход в документы эксперимента и автоматически создаваемые примеры не включены.

### Добавлено

### Исправлено

- Сохранение при выходе и восстановление адаптированы к нативным группам вкладок; сохранена совместимость со старым рабочим пространством: порядок вкладок, выбранная вкладка и несохранённое содержимое.

## [0.12.0] - 2026-08-28

при этом улучшены точность подсветки кода, производительность инкрементального редактирования и определение диапазонов в тексте Unicode.

### Добавлено

- Файлы Swift, Shell, YAML, C/C++ и SQL подключены к синтаксическому разбору и подсветке Tree-sitter.

### Улучшено

- Подсветка редактора начала обновляться инкрементально по области, затронутой правкой: при вводе сохраняются цвета синтаксиса в незатронутых областях, что уменьшает повторное сканирование длинных документов и мерцание.

  а диапазоны подсветки для китайского текста и emoji единообразно переводятся в координаты UTF-16. Остальные языки по-прежнему обрабатываются своими специальными парсерами или инкрементальными лексическими сканерами,
  и для одного документа два разборщика кода одновременно не запускаются.
- TypeScript при том же пороге размера файла подключён к отдельной grammar Tree-sitter, которая поддерживает интерфейсы, аннотации типов, обобщения и другой синтаксис,
  не выражаемый точно grammar JavaScript, и использует тот же инкрементальный кэш и механизм отмены.
- Python при том же пороге подключён к grammar Tree-sitter, что улучшает распознавание блоков с отступами, декораторов, строк, чисел и границ комментариев,
  и использует инкрементальные синтаксические деревья, изолированные по документу и языку.
- CSS при том же пороге подключён к grammar Tree-sitter, что улучшает распознавание селекторов, имён свойств, значений цвета, значений размеров и комментариев,
  и использует тот же кэш инкрементальных синтаксических деревьев, изолированный по языку.
- HTML при том же пороге подключён к grammar Tree-sitter, что улучшает распознавание тегов, атрибутов, строк атрибутов, комментариев и типа документа;
  содержимое скриптов и стилей по-прежнему обрабатывается прежней маршрутизацией языков редактора, чтобы не строить полное синтаксическое дерево для одного документа дважды.
- Swift, Shell, YAML, C/C++ и SQL при том же пороге подключены к grammar Tree-sitter и единообразно используют кэш инкрементальных
  синтаксических деревьев, изолированный по документу и языку; для каждого документа включён только один бэкенд разбора, чтобы старый сканер и Tree-sitter не обрабатывали одно и то же содержимое повторно.

### Тесты

- Добавлены регрессионные тесты для изменённых диапазонов при вставке, удалении, последовательном редактировании, правках нулевой длины, а также в координатах UTF-16 для китайского текста и emoji.
- Добавлены регрессионные тесты Tree-sitter для JavaScript: границы комментариев, строки, диапазоны UTF-16 для китайского текста/emoji и инкрементальные правки.
- Добавлены регрессионные тесты для TypeScript: узлы типов, идентификаторы Unicode, границы комментариев.
- Добавлены регрессионные тесты для Python: отступы, строки, идентификаторы Unicode, границы комментариев и инкрементальные правки.
- Добавлены регрессионные тесты для CSS: селекторы, свойства, цвета, значения размеров и границы комментариев.
- Добавлены регрессионные тесты для HTML: теги, атрибуты, строки атрибутов, текст Unicode и границы комментариев.
- Добавлены регрессионные тесты для Swift, Shell, YAML, C/C++ и SQL: границы комментариев, строки/скаляры, текст Unicode и маршрутизация синтаксических деревьев.

- В боковой панели у верхних заголовков избранного, групп и недавних файлов убраны значки: меньше повторяющихся элементов, остаются число и стрелка сворачивания, которая появляется при наведении.

  поэтому при переносе строк, прокрутке, изменении масштаба и переключении вкладок всё остаётся согласованным.
- Изменение размера окна на лету теперь отправляет не больше одного обновления раскладки за цикл главного потока; во время изменения размера подсветка синтаксиса и прогрев направления приостанавливаются,
  рисование номеров строк больше не ждёт синхронно, а точная раскладка выполняется один раз после того, как край окна отпущен. Это заметно снижает подтормаживания при непрерывном изменении размера.
- Линейка номеров кэширует отображение видимых логических строк для одной области просмотра: повторное рисование, попадание мыши и обратная связь по выделению больше не запрашивают
  раскладку TextKit снова; при прокрутке, изменении текста, сворачивания, шрифта или ширины кэш сбрасывается автоматически.

### Исправлено

- Исправлено: при быстрой прокрутке или переносе строк верхний слой дорисовки линейки мог закрывать соседние номера, а в первой строке могла оставаться старая цифра;
  теперь линейка обрезается по реальной области содержимого окна, а без панели вкладок вместе с текстом уходит из-под строки заголовка.
- Исправлено: после отката линейки к системному рисованию по умолчанию она могла перекрывать область редактирования, и текст становился невидимым; теперь линейка всегда
  использует управляемую собственную точку входа для рисования, и обрезка номеров не влияет на отображение области редактирования.
- Улучшено: обрезка номеров строк у границы строки заголовка: цифры, как и текст, постепенно скрываются границей и больше не пропадают целиком, как только центр выходит за границу.
- Исправлено: при переносе строк номер не был строго привязан к первому визуальному фрагменту логической строки, после прокрутки мог задерживаться или перекрывать соседние номера;

- Исправлено: после изменения размера окна или переключения вкладки цифра первой строки от старой раскладки могла оставаться и накладываться на текущий номер; неактивная вкладка

- Исправлено: верхний номер строки после преобразования координат между представлениями мог застревать на видимой границе и исчезать только с приходом следующей строки;
  теперь положение номера напрямую следует за первым текстовым фрагментом строки и смещением прокрутки редактора и движется непрерывно.
- Обновление линейки при прокрутке и изменении размера окна теперь перерисовывается синхронно в пределах одного цикла главного потока, а во время изменения размера отключено растягивание и сохранение старого backing-содержимого линейки,

## [0.6.0] - 2026-08-05

В этой версии добавлены инструменты кодирования и декодирования текста для ежедневной разработки: они умеют распознавать распространённые закодированные данные, показывают результат в окне предпросмотра, не мешающем
редактированию, и защищают производительность на больших файлах и новый ввод за счёт замены диапазона и проверки устаревания.

- Добавлен единый инструмент «Кодирование и декодирование»: поддерживаются кодирование и декодирование компонентов URL, Base64, Base64URL, сущностей HTML и

  ревизии редактора и исходного текста не даёт устаревшему результату перезаписать новый ввод.
- Автоматическое распознавание ограничено областью в 16 КиБ вокруг текущего выделения или текста под курсором; для Base64 добавлены проверки UTF-8, доли отображаемых символов и минимальной длины,
  чтобы реже принимать за закодированное обычный код.
- Длинные URL и сплошной текст в предпросмотре кодирования и декодирования теперь переносятся по ширине панели, остаётся только вертикальная прокрутка; пункт «Кодирование и декодирование» в контекстном
  меню редактора получил такой же нативный значок, как в главном меню.

### Исправлено

- Запись результата кодирования и декодирования выполняется как одна нативная операция отмены; если во время преобразования продолжается редактирование, прежний предпросмотр устаревает и основной текст не меняется.

## [0.4.0] - 2026-08-03

В этой версии завершено обновление архитектуры производительности для больших файлов: LacEditor плавно работает с обычными текстовыми файлами и кодом до 50 МБ,
а автоматический защитный режим, фоновые задачи и управление памятью снижают влияние больших файлов на редактирование.

### Добавлено

- Добавлен автоматический режим большого файла: при размере свыше 20 МБ или 250 тысяч строк дорогие функции отключаются автоматически; свыше 50 МБ включается
  более строгий защитный режим, о котором предупреждают до открытия.
- В строке состояния и в меню «Вид > Режим большого файла» появились параметры производительности для текущей вкладки: можно временно вернуть перенос строк,
  предпросмотр Markdown, подсветку синтаксиса, сворачивание кода и подсчёт слов в реальном времени, не меняя общие настройки.
- Для открытия, сохранения, поиска, замены всех, обработки JSON и отрисовки Markdown добавлены единое состояние задач, возможность отмены и точки наблюдения за производительностью
  Instruments.

### Улучшено

- Файлы свыше 20 МБ читаются в фоне через отображение в память; сохранение переведено на фоновую атомарную запись, а проверка ревизии содержимого не даёт
  ошибочно пометить файл «сохранённым», если редактирование продолжилось во время сохранения.
- Если окно закрывается или приложение завершается во время сохранения, используется отложенный процесс закрытия macOS, который ждёт завершения фоновой записи; в это время
  главный поток остаётся отзывчивым, а затем продолжается подтверждение несохранённого содержимого.
- Поиск, обратный поиск, замена всех и форматирование JSON переведены на отменяемые фоновые задачи уровня документа; устаревшие результаты не перезаписывают
  новый ввод, а замена всех и форматирование по-прежнему отменяются одним действием.
- Кэш сеансов редактора теперь применяет LRU одновременно по количеству и по оценённой стоимости памяти: общий бюджет неактивного кэша — 64 МБ, сеанс больше
  24 МБ не сохраняется; при росте давления на память система автоматически освобождает неактивные сеансы и восстанавливает выделение и положение прокрутки.
- Для больших файлов включена несплошная раскладка TextKit: через 120 мс после остановки прокрутки заранее раскладывается только одна область просмотра впереди по направлению прокрутки;
  при временно возвращённом переносе строк прогрев останавливается, чтобы не раскладывать далёкие области.
- HTML для Markdown теперь строится последовательно в фоне с проверкой поколения задачи; при ручном включении предпросмотра на большом файле используется задержка 500 мс,
  а после обновления восстанавливается прежняя доля прокрутки.
- Нумерованные списки Markdown сканируют только непрерывный список, которому принадлежит место редактирования, и больше не разбивают и не обходят весь документ.
- В автоматическую обязательную проверку производительности добавлены воспроизводимые тестовые данные на 1/10/20/50/100 МБ: код с короткими строками, журналы со сверхдлинными строками,
  Markdown, JSON, поиск на 50 МБ и открытие 100 МБ по возможности.

- Большие файлы UTF-8 теперь читаются и декодируются в фоне, после выбора файла окно больше не блокируется надолго чтением с диска;
  файлы не в UTF-8 по-прежнему показывают нативное окно выбора кодировки в главном потоке.
- Подсветка синтаксиса теперь вычисляет токены в фоне, цвета применяются пакетами в главном потоке, а версия содержимого и поколение задачи используются, чтобы отбрасывать
  уже устаревшие результаты; при быстром вводе, прокрутке или переключении вкладок обновлять редактор может только последняя задача.
- Для больших файлов кэшируется диапазон подсветки вокруг текущей области просмотра; пока область остаётся внутри кэша, повторное сканирование не выполняется; после остановки быстрой прокрутки
  подсветка конечной позиции дополняется автоматически.
- Обновление линейки номеров при прокрутке теперь объединяется по циклам главного потока, повторные перерисовки после каждой прокрутки убраны, что снижает нагрузку на раскладку и рисование
  TextKit при быстрой прокрутке.
- Окно SwiftUI теперь подключает только редактор текущей вкладки; три последних использованных нативных сеанса редактирования AppKit отделены от кэша слоя представлений,
  и при возврате сразу восстанавливаются выделение, положение прокрутки, история отмены и состояние сворачивания, без прозрачной стопки нескольких больших текстовых представлений.
- Подсветка JavaScript, TypeScript, CSS, Python, Swift, Shell, YAML, C/C++ и SQL переведена на контрольные точки инкрементального лексического анализа:
  примерно каждые 16 КиБ сохраняется состояние многострочного комментария или строки, при прокрутке разбор продолжается с ближайшей контрольной точки, а после правки сбрасывается только состояние
  после затронутой позиции; многострочные конструкции длиннее 64 КиБ тоже раскрашиваются правильно.
- Изменения содержимого файла, курсора, выделения и числа слов больше не рассылаются всему окну одинаково; вкладки, панель инструментов, строка состояния и редактор
  подписываются каждое на нужное ему состояние, и при длительном редактировании лишних обновлений представлений SwiftUI становится меньше.
- При вводе в большом файле содержимое теперь удерживает в реальном времени нативное текстовое хранилище, а полный снимок модели синхронизируется по необходимости только при подсветке, сохранении, поиске, закрытии,
  переносе между окнами или короткой паузе; метка несохранённости по-прежнему появляется сразу после ввода, а полный текст не копируется при каждом нажатии клавиши.
- Номера строк, фон текущей строки и строка/столбец курсора теперь читаются напрямую из изменяемого текстового хранилища TextKit, а перерисовка при прокрутке больше не проходит
  через мост `NSTextView.string` по всему файлу; прокрутка подсветки тоже повторно использует уже синхронизированный снимок.
- В подсчёт слов для больших файлов добавлена задержка при простое: при непрерывном вводе старая задача отменяется, а сканирование начинается, когда текст стабилизируется,
  чтобы фон не обрабатывал снова и снова версии полного текста, которые очень быстро устаревают.
- Обязательная проверка производительности расширена: код на 10 МБ / 200 000 строк, повторное использование инкрементальных контрольных точек, первый экран и середина раскладки TextKit, пакетное применение
  атрибутов в видимой области, фоновое предварительное чтение UTF-8, 10 000 уведомлений о вводе и 10 000 определений строки и столбца, чтобы последующие итерации
  снова не вернули ухудшение производительности на больших файлах.
- Добавлены точки наблюдения Instruments Points of Interest: по отдельности можно анализировать чтение файла, создание или повторное использование редактора,
  раскладку видимой области TextKit, вычисление токенов, применение цветовых атрибутов, синхронизацию модели и время рисования номеров строк.
- В окне с одной вкладкой текст прилегает к верхнему краю, а в окне с несколькими вкладками остаётся небольшой верхний отступ; левый и правый внутренние отступы текста убраны,
  пространство для текста стало компактнее.
- При многострочном выделении подсвечиваются все соответствующие номера строк; при переносе строк номер закреплён на первой визуальной строке, а фон текущей строки покрывает
  все фрагменты переноса всей логической строки.
- В окне с несколькими вкладками номер первой строки теперь выровнен по центру относительно текста; при выделении нескольких строк мышью подсветка номеров обновляется вместе с выделением
  в реальном времени, не дожидаясь отпускания кнопки мыши.
- Номера строк теперь центрируются в линейке по горизонтали и по вертикали, правый разделитель убран; текущая строка выделяется более чётким цветом текста,
  у остальных номеров контрастность снижена, чтобы при просмотре длинных документов было легче найти строку с курсором.
- «Заменить все», одиночная замена, форматирование и сжатие JSON теперь выполняются через нативный редактор, и содержимое
  до операции можно вернуть стандартной командой отмены.
- После успешного сохранения в строке состояния больше не дублируется второе сообщение «Сохранено», нижняя информация остаётся компактной и чёткой.
- У кнопок панели инструментов предпросмотра Markdown появились явные имена для средств доступности, и VoiceOver больше не зачитывает внутренние идентификаторы SF Symbol.

- В светлой теме строка заголовка, редактор, предпросмотр Markdown и нижняя строка состояния теперь используют единый цвет `#FBFBFB`,
  что убирает едва заметную, но ощутимую разницу фона между областями окна; в тёмной теме по-прежнему используется прежний тёмный фон.
- Боковая панель теперь использует системный материал с лёгким эффектом стеклянной прозрачности и правым разделителем, проходящим от верха окна до низа;
  убрана лишняя линия под заголовком «Недавние файлы», чтобы боковая панель была ближе к иерархии нативного выдвижного ящика macOS.
- Область сброса в конце вкладок теперь автоматически занимает всё оставшееся место справа от последней вкладки и сохраняет стабильный минимальный размер, поэтому при перетаскивании
  вкладки в самый правый край больше не нужно точно попадать в узкую зону.
- Панель вкладок переработана в непрерывную полупрозрачную дорожку в стиле Finder в macOS 26: активная вкладка использует тонкий капсульный фон,
  неактивные вкладки отличаются короткими разделителями и откликом при наведении, а кнопка создания стала отдельной круглой кнопкой.
- Если вкладка одна, панель вкладок скрывается автоматически; при создании второй вкладки или возврате к одной область редактирования плавно
  раскрывается или сворачивается вместе с панелью вкладок.
- Ширина вкладки гибко меняется между стабильной минимальной и разумной максимальной в зависимости от места в окне; при большом числе вкладок по-прежнему
  доступны горизонтальный просмотр колесом мыши и затухание у краёв.
- Боковая панель запоминает последнее состояние (раскрыта или свёрнута) и сохраняет его при перезапуске приложения и создании новых окон.
- Значки SF Symbols и отступы текста у команд меню унифицированы, чтобы меню «Файл», «Правка», «Вид» и «Вкладки» выглядели единообразно.

### Исправлено

- Исправлено: при вводе сразу после переключения на новую вкладку прежний редактор ещё мог ненадолго сохранять фокус клавиатуры, и содержимое одновременно записывалось в прежнюю вкладку;
  теперь при отделении от окна редактор сам возвращает first responder, а новое представление при подключении сразу перехватывает фокус.
- Исправлено: полужирное начертание, курсив и ссылки внутри встроенного кода Markdown всё ещё повторно разбирались в предпросмотре; теперь содержимое кода
  всегда показывается как в оригинале.
- Исправлено: крайний случай, когда основной текст точно совпадал с внутренним текстом-заменителем встроенного кода и мог быть ошибочно подменён в предпросмотре.
- Исправлено: если адрес ссылки Markdown содержал подчёркивание, предпросмотр мог ошибочно разобрать фрагмент адреса как курсив и сломать ссылку.
- Исправлено: когда курсор в JSON стоял после закрытого вложенного объекта, команда сворачивания могла ошибочно выбрать предыдущий объект.
- Исправлено: для некоторых некорректных JSON показывалась только общая системная ошибка; теперь читается диагностика разборщика, и в строке состояния показываются
  более точные номера строки и столбца.
- Исправлено: неверный подсчёт номеров строк, строки и столбца курсора и общего числа строк в тексте со старым переносом строки `CR` или разделителями строк Unicode;
  `LF`, `CRLF`, `CR`, U+2028 и U+2029 теперь все считаются одним логическим переносом строки.
- Исправлено: CRLF в Markdown мог считаться предпросмотром за два переноса строки и создавать лишние абзацы, а при особом переносе строки в конце не показывался номер
  последней строки.

- «Поиск и замена» теперь отдельное немодальное окно и больше не является вспомогательной панелью окна редактирования; пока окно поиска открыто, можно свободно щёлкать,

  при закрытии главного окна соответствующее окно поиска закрывается вместе с ним.
- Исправлено: в macOS 26 у кнопки боковой панели и заголовка окна появлялся крупный общий фон со скруглением; заголовок по-прежнему следует за
  состоянием боковой панели.
- Исправлено: инструменты отмены, повтора и режима языка оказывались сжаты рядом с заголовком; теперь верхняя группа действий стабильно закреплена справа в окне.
- Унифицированы фон и разделитель строки заголовка окна, чтобы область боковой панели и область редактирования не имели двух разных фонов, белого и серого.
- Исправлено: после раскрытия боковой панели заголовок окна оказывался на границе боковой панели и области редактирования; теперь заголовок следует за состоянием боковой панели
  и выравнивается над областью редактирования.
- Исправлено: при раскрытии или сворачивании боковой панели частичное обновление линейки номеров могло оставлять старые цифры, и первая строка иногда показывалась
  с неверным номером вроде «41».
- Исправлено: вкладку нельзя было перетащить после текущей последней вкладки; теперь левая и правая половины вкладки соответствуют вставке перед ней и после неё,
  а у фактического края вставки показывается линия-указатель позиции.
- Исправлено: кавычки и экранированные косые черты в литералах регулярных выражений JavaScript и TypeScript ошибочно принимались за строки или комментарии,
  из-за чего последующие многострочные фрагменты кода продолжали раскрашиваться неверным цветом.
- Исправлено: если число вкладок превышало ширину окна, панель вкладок не привязывалась к представлению горизонтальной прокрутки, и колесо мыши не позволяло просматривать вкладки влево и вправо.
- Исправлено: однострочный комментарий кода не заканчивался после символа возврата каретки или переноса строки Unicode, а незакрытая однострочная строка могла заставлять последующий
  код продолжать раскрашиваться неверным цветом.
- Исправлено: окно, созданное через `Command+N`, одновременно показывало системный и собственный заголовок, и заголовок дублировался.
- Исправлено: при переименовании из недавних файлов файла, открытого в нескольких окнах, путь обновлялся только в текущем окне; теперь соответствующие вкладки, режим языка
  и состояние предпросмотра во всех окнах обновляются синхронно.
- Исправлено: после сохранения обычного текста как Markdown предпросмотр не включался автоматически, а при сохранении Markdown в другом формате состояние предпросмотра
  не сбрасывалось синхронно.
- Исправлено: после сворачивания заголовков Markdown и контейнеров JSON скрывался только текст, а большая высота пустого места оставалась; теперь свёрнутая область
  действительно сжимает раскладку, при разворачивании возвращается прежняя высота, а при переходе редактирования или поиска к свёрнутому содержимому оно безопасно раскрывается.
- Исправлено: при вводе в большом файле после того, как курсор прокручен за пределы области просмотра, курсор, область просмотра, строка состояния и номера строк могли рассинхронизироваться; обычный
  ввод и подтверждение через китайский способ ввода теперь возвращают реальную позицию редактирования и очищают старые номера строк, оставшиеся у края линейки.
- Исправлено: при восстановлении системой нескольких главных окон они могли ошибочно использовать одно и то же состояние редактирования; теперь главное окно остаётся единственным,
  а окна, созданные через `Command+N` и отделением вкладки, по-прежнему имеют собственные независимые вкладки и состояние документов.

## [0.3.0] - 2026-07-31

В этой версии переработаны подсветка кода и перетаскивание вкладок, а также улучшена производительность при редактировании больших файлов, переключении вкладок и определении строки и столбца.

### Добавлено

- Перетаскивание вкладок теперь использует родной сеанс перетаскивания macOS: во время перетаскивания видны превью вкладки, следующее за указателем, и место вставки.
- Вкладку можно перетащить прямо в другое окно LacEditor: при отпускании на панели вкладок она вставляется в указанное место, при отпускании на остальной
  области окна добавляется в конец.
- Перед очисткой недавних файлов добавлено подтверждение, в котором сказано, что удаляется только история, а файлы на диске остаются.

### Улучшено

- Переработаны правила подсветки синтаксиса для Markdown, JSON, HTML, JavaScript, TypeScript, CSS, Python, Swift, Shell,
  YAML, C/C++ и SQL: используются сдержанные цвета, подходящие для светлого и тёмного оформления.
- Подсветка сначала распознаёт строки и комментарии, затем обрабатывает ключевые слова, числа и остальные элементы, чтобы один и тот же фрагмент
  не перекрывался последующими правилами по ошибке.
- Скомпилированные правила подсветки кэшируются, что уменьшает затраты на повторное создание регулярных выражений при вводе.
- Редактор и номера строк размечают только текущую видимую область и больше не принудительно размечают весь документ при обновлении курсора или прокрутки.
- Номера строк и положение курсора вычисляются по инкрементальному индексу строк, поэтому после вставки или удаления переноса строки не нужно заново сканировать документ с начала.
- Сохраняется не более 8 последних использованных родных экземпляров редактора: это ограничивает расход памяти и ускоряет переключение между часто используемыми вкладками.
- Во время перетаскивания вкладки макет SwiftUI больше не изменяется непрерывно, что уменьшает дрожание, а если система не вызвала стандартную точку отпускания,
  порядок надёжно определяется по последней вкладке, на которую попал указатель.

### Исправлено

- Исправлено ошибочное распознавание `//`, `#`, `--` и подобных символов внутри строк как комментариев.
- Исправлена окраска ключевых слов, чисел и логических значений внутри строк и комментариев.
- Исправлено срабатывание подсветки полужирного и курсивного начертания для символов выделения во встроенном коде и блоках кода Markdown.
- Исправлено то, что ключи объектов JSON не отличались от обычных строк, а теги в комментариях HTML всё равно подсвечивались.
- Исправлено слишком тёмное фоновое выделение текущей строки в тёмной теме, из-за чего строку с курсором было трудно заметить.
- Исправлено возможное зависание после перетаскивания вкладки за пределы окна, а также нестабильное слияние окон при перетаскивании между окнами и несохранение порядка при перестановке в пределах одного окна.

- На панели инструментов добавлены кнопки отмены и повтора; системное меню и стандартные сочетания клавиш сохранены.

- В нумерованных списках Markdown после нажатия Return автоматически создаётся следующий номер; поддерживаются оба варианта записи, `1.` и `1)`.
- При вставке или удалении пункта в середине нумерованного списка Markdown номера последующих пунктов той же непрерывной последовательности обновляются автоматически;
  ручное изменение номера по-прежнему считается заданным вручную.
- Добавлено распознавание файлов TypeScript, CSS, Python, Swift, Shell, YAML, C/C++ и SQL и базовая подсветка их синтаксиса.
- В контекстном меню недавних файлов можно открыть файл в новом окне, показать его в Finder или удалить отдельно из списка.

### Улучшено

## [0.1.0] - 2026-07-30

Первая работоспособная предварительная версия LacEditor: реализован первый этап возможностей лёгкого редактора текста и кода.

### Добавлено

- Поддерживаются создание, открытие, редактирование, сохранение, «Сохранить как» и закрытие текстовых файлов, а также открытие перетаскиванием и список недавних файлов.
- Поддерживаются файлы TXT, Markdown, HTML, JSON и JavaScript; для JavaScript распознаются `.js`, `.mjs` и `.cjs`.
- По умолчанию используется кодировка UTF-8; если файл не в UTF-8, его можно открыть в кодировке UTF-16, GB 18030, ISO Latin 1,
  Windows Latin 1 или Mac OS Roman.
- Вверху окна расположена панель вкладок: можно переключать вкладки, закрывать текущую, закрывать остальные и закрывать вкладки справа, при этом один и тот же файл не открывается повторно.
- Есть отметка о несохранённых изменениях; перед закрытием вкладки, окна или выходом из приложения запрашивается подтверждение сохранения изменений.
- Редактор поддерживает номера строк, подсветку текущей строки, автоматический отступ, отступ клавишей Tab, отмену, повтор, перенос строк и масштабирование шрифта.
- Единое окно «Поиск и замена» поддерживает поиск предыдущего и следующего совпадения, одиночную замену, замену всех совпадений и учёт регистра.
- Поиск и замена поддерживают экранированные записи `\n`, `\r`, `\t`, `\s`, `\\` и другие, так что можно искать перенос строки, возврат каретки,
  табуляцию, пробел и обратную косую черту.
- Для Markdown, JSON, HTML и JavaScript предусмотрена ненавязчивая подсветка синтаксиса.
- Для Markdown есть предпросмотр в реальном времени с регулируемым разделением на левую и правую части; поддерживаются заголовки, абзацы, списки, цитаты, разделители, ссылки,
  встроенный код, блоки кода и таблицы.
- Для JSON есть команды форматирования и сжатия; если содержимое недопустимо, по возможности сообщаются номер строки и столбца с ошибкой.
- Предусмотрены сворачиваемая боковая панель файлов, дерево файлов, недавние файлы, компактная строка состояния и меню режима языка.
- Поддерживаются три режима оформления: как в системе, светлое и тёмное; есть родные меню macOS и сочетания клавиш.
- Для заголовков Markdown и контейнеров JSON поддерживается базовое сворачивание кода.

### Улучшено

- Редактор основан на родном `NSTextView`; в больших файлах подсвечиваются только видимая область и буфер вокруг неё, чтобы ввод оставался плавным.
- Предпросмотр Markdown использует небольшую задержку (debounce) и проверку версии содержимого, чтобы при быстром вводе всегда показывался самый свежий результат.
- После изменения ширины разделения текстовый контейнер редактора пересчитывается, поэтому длинные строки всегда остаются в пределах текущей области редактирования.
- Меню режима языка в правом верхнем углу показывает и значок типа файла, и название языка, что упрощает узнавание.
- Переработаны вёрстка и размеры окна настроек, чтобы параметры оформления, переноса строк и шрифта были видны полностью.
